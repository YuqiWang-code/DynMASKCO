## 1. Bandits with Knapsacks（BwK）

### 1.1 模型（与本项目同构）【文献确立】

BwK 的标准设置：共 T 轮；每轮到达一个臂 a（或上下文），选择后被接受则获得随机收益 r_t(a)，并消耗随机资源向量 c_t(a) ∈ R^d_+；资源总量固定（"背包"），且**时间本身也常被当作一种资源**。拒绝动作等价于 null arm（r=0, c=0）。

映射到本项目：

| BwK | 本项目 |
|---|---|
| 轮次 t | 订单揭示事件（每天约 200 次） |
| 臂 a | 订单类别（0/1/2，按温区）或其分箱 |
| 收益 r_t(a) | 接受后的净收入（`p_c=0` 时即类别收入 `REV`） |
| 资源消耗 c_t(a) | 预冷能耗 `e_lower`（登记口径） |
| 预算 B | 当天能量预算（登记重算值 710.6548328611384） |
| 最优静态混合策略 | LP 松弛的分数解（我们用它算"遗憾"） |

来源：<https://arxiv.org/abs/2002.00253>；奠基工作 Agrawal & Devanur, *Bandits with Knapsacks*, EC'14（arXiv:1305.2545，**【未核实】**该 arXiv 号，引用前请核对）。

### 1.2 遗憾界【文献确立 + 工程推断】

- 最坏情况下 BwK 的遗憾率 $\tilde O(\sqrt{KT})$ 已被充分理解（$K$ 为臂数、$T$ 为轮数，且预算与 $T$ 同阶时为本率）。【文献确立，见 2002.00253 摘要与正文】
- Sankararaman & Slivkins（arXiv:2002.00253，2020 首发 / 2021 v7）在**最坏情况之外**给出三类结果：① 对数级、实例依赖遗憾率的完整刻画（上下界）；② "simple regret"（逐轮表现）除少数轮外都很小；③ 从 BwK 到 bandits 的**归约**，可套到组合半臂、线性上下文、multinomial-logit 等结构。该文主要分析对象就是 Agrawal–Devanur 的算法。【文献确立，摘要原文】
- **【工程推断】** 我们的情形 $T\approx 200/\text{day}$、$K=3$（类别）甚至更少，$\sqrt{KT}\approx 24$：这意味着**遗憾界的理论量级远大于我们观测到的日间波动**，因此它只能作为"维度升级"的理论语言，**不能**当作"提升 801 单位"的承诺（与用户方案文档的诚实边界一致）。

### 1.3 可实现的算法（选择建议）【文献确立 + 工程推断】

| 算法 | 接受准则 | λ 更新 | 备注 |
|---|---|---|---|
| **LagrangeBwK**（Agrawal–Devanur 原始，primal–dual） | $r_t(a) - \lambda_t^\top c_t(a) > 0$ | 每轮乘性/加性对偶更新，含探索 | 结构最简单、可审计；官方实现在作者仓库（**【未核实】**具体 URL） |
| **UCB-BwK** | 用置信上界 $\hat r + \beta\sqrt{\cdot}$ 与下界 $\hat c - \beta\sqrt{\cdot}$ 替换均值 | 同上 | 需要每臂计数；$K$ 小，方差小 |
| **Thompson-BwK** | 采样后验，取 $P(\text{净收益}>0)$ | 同上 | 需要分布假设（Beta/Gaussian） |
| **\(\lambda_t\) = 剩余预算函数**（我们方案里的 `DynamicPriceCurve`） | $r - \lambda(r)\,c>0$，$r=\text{剩余预算}/B$ | 无学习，纯确定性映射 | 最稳、无超参爆炸；本仓库已实现 |

**我们采用的实现顺序**（已在 `scripts/admission/policies.py` 落地）：
1. `RegisteredShadowPrice` —— 复现登记静态规则（作为对照与热启动）。
2. `DynamicDual` —— $\lambda_{t+1}=\mathrm{clip}\big(\lambda_t+\eta\,(c_t-B/T),0,\lambda_{\max}\big)$，接受准则 $r-\lambda_t c>0$；$T$ 用 **TRAIN** 的期望轮数（不读当日未来）。这是 LagrangeBwK 的确定性单步版本，便于单测与审计。
3. `DynamicPriceCurve` —— $\lambda(r)=\lambda_{\max}-(\lambda_{\max}-\lambda_{\min})r^\gamma$。
4. `FixedThreshold` —— 每 kWh 收入阈值基线。

**【工程推断】** 先跑确定性对偶（无需置信界、无需随机性）能在几十行内验证"动态 > 静态"这一可证伪假设；只有它成立，才值得引入 UCB/Thompson 的探索项。

## 2. 保形预测 / 保形风险控制（CRC）

### 2.1 关键文献【文献确立】

- **Conformal Risk Control**（Angelopoulos, Bates, Fisch, Lei, Schuster；ICLR 2024）：把保形预测推广到"控制任意**单调**损失函数的期望"，算法是 split conformal 的推广，结论紧到 $O(1/n)$；还给分布漂移、分位数风险控制、多重与对抗风险控制、U-统计量期望的扩展。来源：<https://proceedings.iclr.cc/paper_files/paper/2024/hash/f3549ef9b5ff520a7e41ff3cc306ab2b-Abstract-Conference.html>
- 经典 split conformal 的分位数（含有限样本修正）：$\hat q = \lceil (n+1)(1-\alpha)\rceil / n$ 的经验分位数，保证 $P(Y_{n+1}\in C(X_{n+1}))\ge 1-\alpha$（可交换样本）。**【文献确立，标准结论；引用时回 Vovk 2005 / Lei et al. 2018】**
- 在线/滚动窗口破坏可交换性时：Gibbs & Candès 的 **ACI**（adaptive conformal inference）给长期覆盖率而非单步保证。【**未核实**具体版本，引用前核对 arXiv:2106.00170 / 2208.08315】

### 2.2 与本项目的接口【工程推断】

把"接受阈值"保形化，而不是给整个解做预测区间：

```
s_i   = ŷ_i − y_i                     # 例如预测边际净收益 − 实际（用历史冻结日）
q̂_{1−α} = 经验分位（含 (n+1)/n 修正）
接受 ⟺ m̂_it − q̂_m − λ_t·(ê_it + q̂_e) ≥ 0
```

边界（必须写在结果里）：**覆盖保证 ≠ 效用最优**；若只有覆盖率达标而效用无改善，如实记为"校准有效性成立、选择增益未证实"，进 `03_负结果线`。
