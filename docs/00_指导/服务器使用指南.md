## 4. 从本地连服务器

仓库自带三个助手（都从仓库根目录执行，凭据自动读 `sftp.json`）：

```bash
# 跑一条远程命令（退出码 = 远端退出码）
python tools/_srv.py "cd /home/hzeng/project/ZH/MASKCO_v1 && git log --oneline -1"

# 下载 / 上传（参数是**仓库相对路径**；remotePath 自动拼接）
python tools/_sftp_get.py results/foo/summary.json
python tools/_sftp_put.py C-VRP_Cold-chainVehicleRoutingProblem/scripts/foo.py
```

注意：
- **不要**把 `/home/...` 绝对路径作为参数传给这两个 sftp 助手（Git Bash 会做路径转换）。
- `_srv.py` 只是执行命令，**不会**自动 `cd`，命令里请显式 `cd` 到目标目录。

## 5. 跑实验的硬性约定

```bash
# 训练 / 推理的显存策略
export XLA_PYTHON_CLIENT_MEM_FRACTION=0.9    # 训练
export XLA_PYTHON_CLIENT_MEM_FRACTION=0.5    # 推理

# 与他人共享 GPU 时（M0/M1 小模型）
export CUDA_VISIBLE_DEVICES=1
export XLA_PYTHON_CLIENT_PREALLOCATE=false   # 不要一上来占 75%
export XLA_FLAGS=--xla_gpu_autotune_level=0  # 跳过慢速 GEMM autotune
# ⚠️ 小 MLP（H-only probe）与 batch-8 compact decoder 反而要 `unset XLA_FLAGS`，
#    否则报 XlaRuntimeError: CANCELLED: Too small divisible part of the contracting dimension
```

- **> 5 分钟的任务一律 `tmux`**（`nohup` 在 SSH 断线时不可靠）：
  ```bash
  tmux new-session -d -s run1 'bash <你的脚本> > /tmp/run1.log 2>&1'
  tmux ls; tail -f /tmp/run1.log; tmux kill-session -t run1
  ```
- 开跑前 `nvidia-smi` 看显存与占用；GPU 被他人占满时**不要**硬上。
- 每个正式运行使用**独立结果目录**（`results/<登记名>/`），并登记身份（源码哈希 / 数据 sha256 / profile 哈希）；详见 [`文档规范.md`](文档规范.md)。

## 7. 故障速查

| 现象 | 处理 |
|---|---|
| `ModuleNotFoundError: tensorflow` | 只在跑上游 `MASKCO_code/data/*Dataloader` 时出现；扩展侧不需要 |
| `'ArrayImpl' object has no attribute 'value'` | flax 版本 > 0.10.4，降回 0.10.4 |
| `XlaRuntimeError: ... Too small divisible part` | `unset XLA_FLAGS` |
| `: Command not found` / 找不到 conda | 用绝对解释器路径 `/home/hzeng/miniconda3/envs/MASKCO_env/bin/python` |
| 进程被莫名杀掉 | SSH 断线；改用 `tmux`，并检查是否抢占他人 GPU |
| 中文文件名乱码 | `export LANG=C.UTF-8` 或用绝对路径操作 |
