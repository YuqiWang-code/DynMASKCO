## 3. 前沿 AI 收敛成**一个**方向：`VRPS`（Verifier-Rewarded Program Search）

> 四份调研里所有"真杠杆"最后都指向同一件事：**用合法的预测做 rollout，把它当作可验证奖励，
> 在受限程序空间里搜一个"接单/延迟/派车"的策略程序**。其余热点（纯 LLM 解 VRP、
> 换主干 GNN→Transformer→Mamba、CO 基础模型红利、想象未揭示订单）**全部不做**。

### 3.1 三层设计（缺一不可）

| 层 | 内容 | 关键约束 |
|---|---|---|
| **L1 受限 DSL** | 策略 = 表达式程序，只含：价值项 `rev`、`Δins`（插入增量）、`quality_risk`、`arrival_rate`；阈值项 `t̂`、`r`（剩余预算比）、`n_pending`；动作 `{accept(v), reject, defer(τ)}` | **只允许可读已揭示信息**；表达式树深度 ≤6、节点 ≤20 ⇒ 可审计、可反演 |
| **L2 GPU 闭环评估器** | 把"一天"当 batch 维，`lax.scan` 逐单推进；**成本用插入增量**（不是往返）、**预算按 pacing 轨迹**、**未来用已标定到达率生成**（不是真值） | 奖励**必须**来自这个评估器，不许来自代理公式；每次评估输出：均值、最差 regime、预算利用率、违规次数 |
| **L3 搜索** | 进化 + 可选 LLM 提议（FunSearch / EoH 形态）：提议 ≤50 个/代 → GPU 打分 → 保留 top-K（K=8）→ 变异；每代把 top-1 送**反演门** | 反演门 `AUC>0.98 且损失<5%` ⇒ `RULE_CAPTURABLE` ⇒ 该程序降为基线，不许当创新点 |

### 3.2 为什么这个是"最可能实现"的

1. **它修的是唯一被证明错的东西**：价值函数（§0 F5 与第 162 轮根因）；
2. **它不需要改协议、不需要新数据**：只在接单/延迟/派车动作空间上搜程序，环境与数据全用现成的；
3. **它天然抗"调参"指控**：奖励来自闭环仿真、每个程序带反演门结论；
4. **它有清晰的失败判据**：三块盲测不跨零即关闭，不追加第三轮。

### 3.3 预测层的合法边界（写死，泄漏审计必须覆盖）

* 预测只用两类输入：①TRAIN 日的经验到达率/类别比例；②**当日已揭示**的计数与时刻。
* 单元测试必须断言：评估器在任何决策点读取的 `reveal_time` 集合 ⊆ `{≤ clock}`；
  一旦读到未来，测试**非零退出**（沿用 `verify_no_future.py` 的 L2 `visibility` 检查，新增 `rollout_visibility`）。
* 预测输出**分布/分位**，策略使用**置信下界**（25% 分位），不用均值 —— 这是 robustness 的来源。

## 5. 定理线（B）：把 1/3 与 3/5 做成干净紧界

**已有**：确定性上确界 1/3（枚举 2 个纯策略）、最优随机化 3/5（二维族 (p₁,p₂) 网格，最优点 (0.6,1.0)）、阈值族 ≤1/3（20001 个 ρ 扫描）、与 η 无关（五档恒等）。

**缺的四块砖（必须全部补齐才算定理）**：

| 砖 | 做法 | 工具 |
|---|---|---|
| ① 上界 LP | `min t s.t. Σ_j x_j·ALG(A_j, I_k) ≥ t·OPT(I_k), Σ_j x_j = 1` | `fractions.Fraction` 精确求解 |
| ② Yao 下界 LP | `max s s.t. Σ_k q_k·ALG(A_j, I_k)/OPT(I_k) ≤ s, ∀j` | 同上，证 3/5 紧 |
| ③ 阈值类解析上界 | 把 ρ 参数化后**解析**求最大（不是扫描），得"任何阈值型策略 ≤ 1/3 且取等" | 符号推导 + 有理数校验 |
| ④ 可重跑验证器 | **独立计算 OPT**，不复用仿真/训练代码路径（G3 审计已暴露该风险） | `scripts/theory/verify_certificate.py` + 反例套件 |

**T2（正面定理，配 §3 的预测层）**：单资源 + 预测的三段式——consistency（预测准确时 ≥ 1−ε）、
robustness（预测全错时仍 ≥ 常数）、smoothness（误差 δ 时损失 O(δ)）；预测定义为"最优接受集合的最小净效用"。

**明确不写成定理**：神经网络达到常数竞争比；把 32%/68.5% 当普遍常数（应记 β）；"扫描取等"当阈值类最优；仿真平均比当竞争比。

### 11.2 γ≈0.86 说明**成本缩放不是 −12.1% 的主因**（重要）

γ 只比 1 小 14% ⇒ 欧氏往返近似只**轻微**过罚，**不足以解释第 162 轮闭环 −12.1%**。
那么 −12.1% 更可能来自**阈值坐标系错位**：

| 量 | 仿真 | 真实环境 |
