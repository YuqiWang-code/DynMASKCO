# 预登记 INV-1：接拒策略的决策反演（规则可捕获门槛）

> 登记时间：2026-10-18（**先于执行**）｜ 依据：总纲 §1.2 / §7.2 / §11.2 的合入门槛
> 目的：按总纲的硬纪律，把"我们自己的三个接拒策略"先过一遍反演测试 —— 如果它们都能被 depth≤3 的树复现且效用损失 <5%，那它们就**只能当基线**，不得再作为创新点。

## 1. 假设（可证伪）

> **H-INV**：静态 λ、动态对偶 λ、学习型 λ（v2，7 参数线性）三者的接拒决策，都能被**只用在线可见特征**的浅模型（决策树 depth≤3）在留一日（leave-one-day-out）上以 **AUC > 0.98** 复现，且蒸馏后净价值损失 **< 5%**。

若某策略不满足（AUC ≤ 0.98 或损失 ≥ 5%）⇒ 判 `NOT_CAPTURED`，该策略保留"可能存在非规则结构"的资格（仍不等于有效）。

## 2. 数据与口径

| 项 | 值 |
|---|---|
| 数据 | 登记 GATE 40 实例前 5 天（seed 20260926，每日约 193 单 ⇒ ~965 条决策） |
| 预算 | B = 710.6548328611384 |
| 成本口径 | 预冷 `e_lower`；净价值 = `REV − 1.0·燃油 − 1.0·品质`（燃油 = 0.1 元/km × 20 km × depot 往返绕行；品质 = PVAL·q·(1−exp(−K_EFF·dwell))） |
| 特征（10 维，全部在线可见） | `clock/16`、`budget_ratio`、`e_hat`、`revenue`、`ratio=rev/e`、`seen`（当日进度）、`spent`、`cls0/1/2` one-hot |
| 模型 | ① 决策树 `max_depth=3`；② 逻辑回归（默认 L2） |
| 评估 | **按日簇留一**：留出 1 天做测试、其余 4 天训练，报 5 折的平均 AUC |
| 蒸馏对照 | 用全量数据训练同一棵树，把它当策略重放（预测 accept ≥0.5 且预算允许），比较净价值 |

## 3. 判据（机械）

```
RULE_CAPTURABLE  ⟺  mean_LOO_AUC(tree) > 0.98  且  |loss_tree| < 5%
否则               NOT_CAPTURED
```

## 4. 预算与止损

- 计算量：5 天 × 3 策略 × 5 折 = 75 次拟合，秒级；预算上限 10 分钟 CPU。
- 止损：若任一策略 AUC 与 0.5 无法区分（<0.6）且损失 > 20%，说明反演脚本本身失效 ⇒ 先修工具，不判科学。

## 5. 不主张

1. 反演只针对**接拒层**，不覆盖闭环（closed-loop）行为；`NOT_CAPTURED` 不等于"有增益"。
2. 10 维特征表不是穷尽的；树 depth=3 也不是最强的规则类。
3. 结论只覆盖"本实现 + 这 5 天"，不外推到全部动态冷链问题。
4. 若三策略都被判可捕获，**不改写** `stable_online_gain=False`，只是把它们的定位降为基线。
