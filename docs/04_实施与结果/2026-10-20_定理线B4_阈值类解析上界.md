## 1. 模型（与 `audit_g3_recompute` 同一登记口径，本文件独立重写）

- 预冷能耗 `e = q·k·(25 − T_class)`，`k=0.15`，`q=2`；`e_L = 21/10`（18℃）、`e_H = 129/10`（−18℃）；
- 收入 `r_L = 10 < r_H = 30`；预算 `B = e_H + η`，`0 ≤ η < e_L`；
- **实例 A**：只有 L；**实例 C**：先 L，若拒 L 则 H 出现（预算仍为 B）；
- `OPT_A = r_L`，`OPT_C = r_H`，报价比 `d_L = r_L/e_L = 100/21`、
  `d_H = r_H/e_H = 100/43` ⇒ **`d_H < d_L`**（上一轮修正过的守卫，本轮在公式里显式带着）；
- **常数密度阈值策略**：`accept ⟺ r/e ≥ ρ`，且须 `e ≤ 剩余预算`。

## 2. 命题（本轮结论）

**命题 a（闭式）**：对任意 `ρ ≥ 0`，

```
w(ρ) = (r_L / r_H) · 1[ρ ≤ d_L]          （= 1/3 或 0）
```

⇒ `sup_{ρ≥0} w(ρ) = r_L/r_H = 1/3`，且**与 `d_H` 的大小关系无关**。

*证明*：把 ρ 轴按 `{0, d_L, d_H}` 分成至多 3 段，逐段穷举：
- `ρ ≤ d_L`：L 在两实例上都被接受 ⇒ `ratio_A = 1`，`ratio_C = r_L/r_H`（接了 L 后
  剩余 `B − e_L = e_H − (1−η)e_L < e_H`，H 不可行，用了 `η < e_L`）⇒ `w = r_L/r_H`；
- `ρ > d_L`：L 在两实例上都被拒 ⇒ `ratio_A = 0` ⇒ `w = 0`。
（`d_H` 只决定"拒 L 时 H 是否可接"，但 `ratio_A = 0` 已经压死最坏比，故不影响 sup。）
脚本对 `η_frac ∈ {1/10, 1/2, 9/10}`、每个分段点与区间代表点、外加 200 个随机有理 ρ
逐点核对闭式，**全部相等**。

**命题 b（随机化后回到最优）**：阈值族只有两个"纯"收益向量
`接L = (1, 1/3)`、`拒L = (0, 1)`；混合 `x`（接 L 的概率）得最坏比
`min(x, 1 − 2x/3)`，在 `x* = 3/5` 取到 `3/5`。
⇒ **`1/3 → 3/5` 的差距完全来自随机化，不来自阈值结构本身**；阈值族一旦随机化就达到
LP 上界（与 B2 的 `x* = (2/5, 3/5)` 同一个点、同一个值）。

**命题 c（对旧证据的重新解读）**：`w(ρ)` 是分段常数，取值集合**只有 `{0, 1/3}`**；
脚本用 `n=2001` 复刻扫描，`distinct values = {0, 1/3}`。
⇒ 20001 点网格扫描**原理上**不可能看到 1/3 以外的数，它既不能证明也不能反驳"阈值族可超越 1/3"；
F5 的 `+0.27%` 只能读作"**确定性**阈值族在真实实例族上无改善空间"，不能读作"阈值方向被穷尽"。

## 3. 一处自我更正（必须留档）

我在推导过程中先写下过"混合的 ≤ 1/3 仍是 ≤ 1/3"——**这是错的**：
`min_k E[·] ≥ E[min_k ·]`，混合可以让最坏比上升。正确结论见命题 b（混合后到 3/5）。
错因是把"最坏比的平均"当成"平均的最坏比"。此更正不改变 B2/B3 的任何结论，反而与它们相互印证。
