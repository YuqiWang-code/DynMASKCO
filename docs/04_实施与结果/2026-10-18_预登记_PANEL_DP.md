# 预登记：DP 门控的全仿真 5 日面板（PANEL-DP）

- 日期：2026-10-18
- 类型：**预登记**（正式面板实验）
- 上游依据：[D4 v3 因果 DP](2026-10-18_D4v3_因果DP.md)（接拒层 +1.45%，5/5 天）、[路线裁决修订](2026-10-18_路线裁决修订_D4v3.md)（I-2 部分复活）

## 1. 要检验的假设

H-PANEL-DP：**在接拒层（表级）观察到的 DP 状态依赖阈值收益，能迁移到全仿真日效用口径。**

D4 v3 的 +1.45% 是接拒层的净价值（收入 − 燃油 − 品质代理），不含路径重算、时间窗违约、车辆数变化。阶段 1/1b/1c 的教训是：接拒层的 +38 收入代理**没有**迁移到日效用（动态 λ − 控制 = −25.75）。因此本实验是"迁移检验"，不是"再接一次表级"。

## 2. 实验设定（冻结）

| 项 | 值 |
|---|---|
| 入口 | `C-VRP_Cold-chainVehicleRoutingProblem/scripts/evaluation/run_admission_panel.py` |
| 臂 | `dp`（本次）；对照臂来自同配置历史运行：`control`/`static`/`dynamic`（阶段 1）、`marginal fw=1`（阶段 1b）、`marginal fw=5`（阶段 1c） |
| 天数 | 5（GATE 集，`--days 5`） |
| 数据集 | GATE（`--dataset gate`，默认） |
| DP 价值表 | `results/causal_dp/v1/dp_v.npz`（`--dp-npz`，1.6 MB，由 `run_causal_dp.py --save-v` 生成） |
| 阈值离散化 | 预算步长 0.25（`round`，非 `ceil`），价值表按日预算比例索引 |
| 输出 | `results/admission_panel/stage2_dp/{panel.json,panel.md}` |
| 重算器 | `DPGateReplanner`（继承 `SaaReplanner`） |

**对照臂的可比性前提**：阶段 1/1b/1c 与本次必须同为 GATE 5 天、同一 seed、同一成本参数、同一 `distance_cost`/`coldchain_cost` 口径。若发现任一不一致，Δ 判读降级为 `DEVELOPMENT_DIAGNOSTIC` 并写明。

## 3. 判据（先冻结，事后不改）

主指标：`mean_delta_dp_minus_control`（DP − 控制，逐日配对的 5 日均值，日效用口径）。

| 判定 | 条件 | 标签 |
|---|---|---|
| **LEAD** | Δ(DP − 控制) > 0 **且** Δ(DP − 静态) > 0 **且** 5 天中 ≥4 天为正 | `LEAD` |
| **WEAK-LEAD** | Δ(DP − 控制) > 0 但 Δ(DP − 静态) ≤ 0 | `WEAK-LEAD` |
| **DOMINATED** | Δ(DP − 控制) ≤ 0 | `DOMINATED` |

- 若 `DOMINATED`：DP 与阶段 1 的动态 λ 同命运，接拒层收益被距离/品质损耗吃掉的结论**再加一条独立证据**；I-2 状态依赖分支标记为"仅表级有效"。
- 若 `WEAK-LEAD`：正增益来自"有门控"这件事，而非 DP 的状态依赖；按阶段 1b 的同一逻辑，需再做"DP vs 同接受率的静态阈值"消融才能归因。
- 若 `LEAD`：I-2 状态依赖分支升为主线，下一步做 OCRS 与路由耦合两半。

辅助报告（不参与判定，但必须列出）：接受率、预算利用率、`candidate`/`accepted`/`closed_loop` 三列、逐日 Δ 序列（含符号）。

## 4. 止损

- 若面板 90 分钟未产出 `panel.json` 且日志无逐日行 ⇒ `BLOCKED(infra)`，记录现象后重跑一次；两次失败则改本地/GPU 队列执行。

## 5. 这不能证明什么（预写）

- 5 天、单一 GATE 集、单一 seed：**不足以**声称统计显著或跨分布稳健。
- DP 价值表来自 D4 v3 的简化设定（表级状态），全仿真状态空间更富，DP 可能是**过度简化**而非"最优因果策略"——`DOMINATED` 不能被解读为"状态依赖无价值"。
- 本实验只测"迁移"，不测"上限"；即使 `LEAD`，也不等于存在可发表的因果增益幅度。
