- 日期：2026-10-18

## 1. 构造（两单、一车、一个能耗预算，可精确枚举）

- 订单 L：18 °C，$q=2$ ⇒ $e_L = 0.15\cdot 2\cdot 7 = 2.1$，$r_L = 10$，密度 $d_L = 4.762$；
- 订单 H：−18 °C，$q=2$ ⇒ $e_H = 0.15\cdot 2\cdot 43 = 12.9$，$r_H = 30$，密度 $d_H = 2.326$；
- 预算 $B = e_H + \eta$，取 $\eta = 0.5\,e_L = 1.05$ ⇒ $B = 13.95$；
- 于是 $e_L + e_H = 15.0 > B$ ⇒ **至多能服务一单**；L 在 0 时刻揭示，H 在 $\delta$ 后揭示。

注意 $d_H < d_L$：**收入比 3×，能耗比 6.14×** ⇒ 高价值温区的密度反而更低。

## 2. 证书（逐位核对）

| 量 | 值 |
|---|---:|
| 预知最优 `OPT` | **30.0**（拒绝 L、接受 H） |
| 阈值族最好成绩 | **10.0**（ρ ≤ 4.762 时接受 L，随后 H 越限） |
| **`ALG/OPT` 上界** | **1/3 = 0.3333** |

逐 ρ 枚举（`results/bench/hard_C_certificate.json`）：

| ρ | 决策 | ALG | ALG/OPT |
|---:|---|---:|---:|
| 0.0 | 接 L，H 越限 | 10.0 | 0.3333 |
| 2.326 (= $d_H$) | 接 L | 10.0 | 0.3333 |
| 3.544 | 接 L | 10.0 | 0.3333 |
| 4.762 (= $d_L$) | 接 L | 10.0 | 0.3333 |
| 4.762+ε | **L 与 H 都拒**（$d_H < d_L$） | **0.0** | 0.0 |
| 9.524 | 都拒 | 0.0 | 0.0 |

⇒ **对所有 ρ，`ALG/OPT ≤ 1/3 < 1`**。这不是"调参没调好"，而是这一族的**结构性上限**。

## 3. 为什么这条比前面所有实验都重要

它把三条独立证据串成一条因果链：

1. **理论**：密度阈值族在存在"高价值/高能耗"订单时结构上无法最优（本证书）；
2. **实测**：五个温区排除变体全负（[PANEL-TIER](2026-10-18_PANEL_TIER_执行记录.md)），OCRS 可表达子族全负（[PANEL-OKP](2026-10-18_预登记_PANEL_OKP.md)）；
3. **机制**：控制臂服务率 0.708/0.597/0.312 说明系统已在做密度排序。

**因此接拒层不是"还没调好"，而是"这一族的上限就在那里"** —— 这正是 [路线裁决](2026-10-18_路线裁决_接拒层关闭.md) 落 §4.4 第三支的理论依据。

同时，本证书**精确刻画了未来信息的位置**：要拿到 OPT=30，策略必须知道（或以某个信念推断）"后面会来一单 H"。
这正是 $L_{\text{future}} = 2.31\%$ 的微观形态 —— 未来信息的价格 = 在构造 C 上 $1 - 1/3 = 2/3$。

## 4. 这不能证明什么（必须写）

- 这是**一个实例的证书**，**不是**一般性下界定理。要成为定理，需要参数化族的完整证明，且下界必须覆盖
  **任意（含随机化、含信念）因果策略**，而本脚本只枚举了确定性密度阈值。
- 模型只覆盖"单资源 + 两单 + 无路由"的接拒抽象；**不含**容量、时间窗冲突、多车派车、路线耦合。
  因此它**不**说明真实实例上的最优差距有 2/3。
- `η_frac = 0.5` 是一个取值；证书对任意 $0<\eta<e_L$ 同型成立（构造已参数化），但本文只跑了该点与网格。
- 与实测的连接是**解释性**的，不是同一口径的数值对应（实测是 200 单/日的闭环，这里是 2 单抽象）。
