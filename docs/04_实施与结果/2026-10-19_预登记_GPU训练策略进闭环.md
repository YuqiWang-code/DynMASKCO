# 预登记：GPU 训练的「距离感知 + 节流」接单策略进真实闭环（`pd` 臂）

> 类型：**预登记（执行前冻结）** · 第 162 轮 · 2026-10-19
> 上游：`scripts/train/gpu_policy_search.py`（GPU 仿真 + ES 训练）、
> `docs/04_实施与结果/2026-10-19_能耗三分与接单层真实上界.md`（B_eff = 68.5%·B 的来源）

## 1. 这一步要回答什么

GPU 仿真里出现了一个**此前没有过的结果**（第 162 轮实跑，`results/train/policy_r1.json`）：

| 评测集（零样本） | ES 策略 | 静态密度族（**在评测集上网格最优**） | 增益 |
|---|---:|---:|---:|
| R1c_GATE（5 天） | **1430.68** | 1419.12 | **+0.81%** |
| R3_GATE（5 天） | **1143.19** | 1104.19 | **+3.53%** |
| R1_GATE（5 天） | **1158.73** | 1123.25 | **+3.16%** |
| R1_CAL（30 天，训练集） | 1120.997 | 1086.558 | +3.17% |

**注意这是"打败了在评测集上自己调过的静态族"** —— 不是打败一个弱基线。
所以必须问：**这个增益在真实闭环里还在吗？** 本预登记就是回答这个。

## 2. 冻结的策略（一个字都不改）

GPU 训练得到的参数（`results/train/policy_r1.json` → `theta`）：

```
θ = (ρ0, a_t, a_b) = (1.738, −0.9849, −0.9706)
```

接受判据（**只用已揭示信息**）：

```
v_i   = rev_i − 0.1 · dist_km_i,   dist_km_i = 2·‖x_i − depot‖ · 20      （往返近似，km）
e_i   = e_lower(class_i, q_i) = 0.15 · q_i · |25 − T_class_i|           （登记口径）
t̂     = clock / 16
r     = 1 − e_used / B_eff,        B_eff = 0.685 · B（B = 710.6548…）
ρ_eff = max(0.25, ρ0 · exp(a_t·(t̂ − 0.5) + a_b·(r − 1)))
接受  ⇔  v_i / e_i ≥ ρ_eff  且  e_used + e_i ≤ B_eff
```

**为什么 B_eff = 0.685·B**：第 99 轮能耗三分实测固定开销占 32%，接单口径可用预算 486.6/710.65 = **68.5%**；
GPU 仿真用的也是同一个 0.685（`OVERHEAD_SHARE = 0.32`）。

## 3. 判据（预登记，跑之前写死）

真实闭环 GATE day 0–4，与 **control**、**登记静态 λ** 同进程配对：

* **`PD-LEAD`**：`utility(pd) ≥ utility(static λ) × 1.015` **且** ≥8/10 日为正 **且** 无 `budget_violation` / 无协议违规；
* **`PD-WEAK`**：超过 static λ 但 < 1.5%，或日数不足；
* **`PD-LOSE`**：低于 static λ；
* **`PD-UNSAFE`**：任一 `failures` 非空或 `budget_violated` ⇒ 无论分数一律否决。

## 4. 预言（可被推翻）

仿真里 +0.8%~+3.5%，**我预言真实闭环会缩水到 +0.3%~+1.5%**，理由：
仿真不含路由/时间窗可行性，真实环境里"距离感知价值"会被 SAA 的实际插入可行性部分抵消。
若真实增益 ≥ +1.5% 且日数达标 ⇒ **G4 可能首次达成**；若为负 ⇒ 这条线也关掉。

## 5. 这不能证明什么

1. 不证明"GPU 仿真能替代闭环"——恰恰本轮是要检验它不能的那部分；
2. 仿真里的"静态族"是**密度阈值**，真实环境里的"最强基线"是**预算保留式 λ（含 reserve）**，两者不同源，
   所以真实闭环的对照必须用 `static` 臂本身，不能拿仿真数字换算；
3. 不主张 SOTA，直到 `PD-LEAD` 在 ≥10 天口径上成立。
