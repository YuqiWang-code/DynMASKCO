# 反演门判定（解析，不需实验）：攒批发车规则 **`RULE_CAPTURABLE`** ⇒ 降级为基线

- 日期：2026-10-18
- 类型：**合入门槛判定**（总纲 §1.2）
- 上游：[PANEL-BATCH 执行记录](2026-10-18_PANEL-BATCH_执行记录.md)（§8 已预写预期）、
  [G4 达成/未达成两句读](2026-10-18_G4达成_十日盲测.md)

## 1. 为什么这次不需要跑实验

总纲 §1.2 的反演门问的是：**能否用 depth-3 决策树复现该策略的决策，且效用损失 <5%**。
若"能"，说明该策略没有超出"浅树规则"这个假设类 ⇒ `RULE_CAPTURABLE` ⇒ 降级为基线。

而 `BatchedDispatchReplanner` 的**全部**决策是：

```
accept(i)  ⟺  REV[c_i] − λ*·e_i > 0                    （登记静态价，一个阈值）
dispatch   ⟺  |pending| ≥ K  或  clock − min_reveal(pending) ≥ W   （两个阈值）
```

两个判定都是**标量阈值比较**，其特征维度是 2（`|pending|`、`oldest_wait`）+ 1（静态价判据）。
`depth-3` 树可以精确表示任意 2–3 维轴对齐阈值合取/析取 ⇒ **该策略天然落在 depth-3 树类内部**，
复现损失为 **0**（不是"小于 5%"，是**精确等价**）。

⇒ **判定 `RULE_CAPTURABLE`。** 这是**可表示性事实**，不是经验结论，因此无需再跑 INV 实验；
跑实验只会得到同一结论（AUC = 1.0、损失 = 0）而多烧一轮机时。

## 2. 后果（按纪律执行，不打折）

按总纲 §1.2 与 §11.3：

1. **"攒批发车"不是创新点**，降级为**基线/消融**；它进论文的位置是"派车时机这一维的规则基线"，
   而不是"我们的方法"。
2. 它的价值仍然真实：**在全新十日留出上对控制臂 +4.44%（10/10 日）、对静态 λ +1.59%（7/10 日）**，
   这把它变成**该领域一个强基线**，而不是我们的贡献。
3. 由此，[路线裁决](2026-10-18_路线裁决_接拒层关闭.md) 的"主线 = I-1 + I-3"**不变**；
   I-2 依然不能被复活——因为复活需要"不可被浅树复现的机制"。

## 3. 那还剩什么是可做的（诚实清单）

| 方向 | 是否超出浅树类 | 现状 |
|---|---|---|
| 接拒层阈值族（8 个机制） | 否（都已判或可判 `RULE_CAPTURABLE`） | 已测尽（≤0.48%，4200 天 GPU） |
| 攒批发车（K/W） | 否（本记录） | 对控制臂 MET、对最强基线 NOT MET |
| **路线构造（3.47× 差距）** | **是**（构造是搜索/学习问题，非阈值） | **尚未真正进入闭环**：GPU 松弛得到 −8.03%，但它不进闭环 |
| 离线重优化型基线（PyVRP 每决策点重排） | 是（但属外部求解器，不是我们的机制） | 通道已打通（VRPTW 冒烟 OK），未接面板 |

⇒ **下一步唯一还没被否掉、且天然超出浅树类的方向是"路线构造"**：把 GPU 训练的打分器
（5 天 −8.03%）以**构造器**身份接进闭环，而不是以阈值过滤器的身份。这也正是
[3.47× 记录](2026-10-18_里程余量_347倍.md) 指向的余量所在。

## 4. 这不能证明什么

- `RULE_CAPTURABLE` **不**表示该规则无价值，只表示它不构成方法学创新。
- 也不排除"K/W 规则 + 更好的路线构造"组合后仍然有效——那属于上表第三行的工作，不是本记录的结论。
- 本判定是解析的，未经独立复核；若复核者认为应当实测，实验成本约 1 天面板 + 1 次树拟合。
