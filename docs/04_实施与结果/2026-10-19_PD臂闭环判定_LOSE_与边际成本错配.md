# `pd` 臂闭环判定：**`PD-LOSE`（−12.1%）** —— 错在"往返距离"这个边际成本模型

> 类型：**预登记检验 + 负结果 + 根因定位** · 第 162 轮 · 2026-10-19
> 预登记：`2026-10-19_预登记_GPU训练策略进闭环.md`（判据 `PD-LEAD` = ≥ static λ ×1.015 且 ≥8/10 日且无违规）
> 产物：`results/admission_panel/p162_pd_5d/panel.json`（5 天，GATE day 0–4）

**预言也被推翻**：我事前写"真实闭环会缩水到 +0.3%~+1.5%"，实际是 **−12.1%**——不是缩水，是反转。

## 2. 根因：仿真里的"距离"是**往返**，闭环里的边际距离是**插入增量**

`pd` 五天的能耗只用了 **565–651 / 710.65（80–92%）**，而控制臂是 99.6%、静态 λ 是 98.0%。
**它把预算留在了桌上**——服务单 86–120，静态 λ 是 108 但收入更高。

为什么？GPU 仿真里我给每单估的距离是 `2·‖x − depot‖`（每单独立往返），而真实环境里
**车辆已经在路上**，多加一单的**边际**里程远小于一次完整往返（第 99 轮实测：每单里程 ≈ 4.7 km，
其中大量是与已有路线共享的）。⇒ `v = rev − 0.1·dist_roundtrip` **系统性低估**了远单的价值 ⇒
拒绝过多 ⇒ 收入掉、预算用不满。

这条与既有证据一致：`marginal` 臂（用**边际**净价值、含距离项）在 10 天口径是 **+0.87%**，
**不是负的**——差别就在"边际"两个字。

## 3. 这轮的真正产出（比数字重要）

1. **GPU 仿真不是闭环的替代品**：同一个策略在仿真里 +0.81%~+3.53%（还打败了评测集调优的静态族），
   在闭环里 −12.1%。差异全部来自**成本模型**（往返 vs 边际）。
2. **可迁移的是结构，不是数值**：仿真给出的结构（门槛随时间下降、随剩余预算收紧）在闭环里没坏
   （`pd` 五天都合法、无违规、能耗曲线平滑），**坏的是价值函数里的距离项**。
3. 因此下一步是明确的一步：**把仿真里的距离换成"插入增量距离"**（环境里有现成的 `_delta_ins` 口径），
   其余结构（θ 的三参数形状）保留。

## 4. 这不能证明什么

1. 不证明"距离感知"方向错——`marginal` 臂（边际口径）+0.87% 说明方向不反；错的是**往返近似**；
2. 不证明仿真训练无用——它给出的"结构"在闭环里没坏；
3. 不主张 SOTA；`G4` 仍未达成（`pd` 未超过 strongest baseline）。
