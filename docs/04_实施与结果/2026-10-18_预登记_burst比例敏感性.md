# 预登记：burst 比例敏感性（0.1 / 0.5）——regime 结论是否只是 0.3 这个点

- 日期：2026-10-18（继续迭代，第 94 轮）
- 类型：**预登记**（判据先写，结果未出）
- 上游：[burst regime 十日：G4 口径 MET](2026-10-18_burst_regime十日_G4口径达成.md)、
  [十日报表：两 regime 翻转](2026-10-18_十日报表_两regime翻转.md)

## 1. 要检验什么

已观测（burst = **0.3**、slot = 0.25 h、5 天）：

| 量 | 无并列 | burst 0.3 |
|---|---:|---:|
| 控制 | 1808.53 | 1787.91 |
| 静态 λ | 1828.65 | 1816.79 |
| Δ% | +1.11% | **+1.62%** |

问题：**"+1.62%" 是 burst 机制带来的，还是 0.3 这个点恰好挑出来的？**

## 2. 假设

H-RATE：静态 λ 相对控制的 Δ%（5 天口径）随 burst 比例**单调上升**：

```
burst 0     →  +1.11%
burst 0.1   →  介于 1.11% 与 1.62% 之间
burst 0.3   →  +1.62%（已测）
burst 0.5   →  ≥ 1.62%
```

机制理由：并列到达时"先到先得"的代价更大（一次涌入的订单质量差异被放大），
因此过滤的价值应随并列比例上升。

**反向假设**：若 0.1 与 0.5 都在 +1.1% 附近（与无并列无差别），则 0.3 的 +1.62% **是点选**，
"regime 影响 Gate"这一说法必须降级为"**单点观察**"。

## 3. 设定（冻结）

| 项 | 值 |
|---|---|
| 入口 | `run_admission_panel.py --days 5 --burst-slot 0.25 --canonical-ties` |
| A 组 | `--burst-rate 0.1`（control / static）→ `br01_{control,static}` |
| B 组 | `--burst-rate 0.5`（control / static）→ `br05_{control,static}` |
| 天数 | 5（与已测 burst 0.3 的 5 天口径一致，便于对照） |
| 已测参照 | burst 0.3：控制 1787.91 / 静态 1816.79（Δ +1.62%）；无并列：1808.53 / 1828.65（Δ +1.11%） |

## 4. 判据（先冻结）

记 `d(r)` = burst 比例 r 下静态 λ 相对控制的 5 日均值 Δ%。

| 判定 | 条件 |
|---|---|
| **RATE-MONOTONE** | `d(0.1) ≤ d(0.3) ≤ d(0.5)` 且 `d(0.5) ≥ 1.5%` |
| **RATE-WEAK** | 非单调，但 `d(0.1)` 与 `d(0.5)` **都** ≥ `d(0)`（=1.11%） |
| **RATE-POINT** | 任一 `d(r) < d(0)` ⇒ 0.3 的结果判为**点选**，regime 结论降级为单点观察 |

## 5. 止损

- 任一臂 `hard_feasible=False` ⇒ 该日计入分母并显式报告；≥2 天 ⇒ `BURST-UNSAFE`。

## 6. 这不能证明什么（预写）

- 5 天、单集单种子；即使单调，也只支持"**在本 GATE 集上**过滤价值随并列比例上升"；
- burst 语义仍是**自定义**（把 reveal_time 对齐到 0.25 h 网格），不是真实订单流的计量结果；
- 不改变 G4 主状态（无并列 regime `NOT MET`）；
- 未测 slot 宽度（0.25 h 之外的 0.1 / 0.5 h 未扫）。
