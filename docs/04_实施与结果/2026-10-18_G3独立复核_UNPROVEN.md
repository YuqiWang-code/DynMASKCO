## 2. 两处 HIGH 级错误（必须记下来）

### H-1｜"未来信息的价格 = 2/3" 是**错的**（G3-a §3 第 49–50 行）

原文主张：要拿到 `OPT=30`，"策略必须知道（或以信念推断）后面会来一单 H"。

**复核反驳**：任何常数阈值 `ρ > d_L`（例如 ρ=5），或"拒 18°C 类"，都是**纯因果**、不需任何未来信息，
在该实例上得分**正是 30 = OPT**。因此在构造 C 上，**因果最优 = 预知最优，信息价格为 0，不是 2/3**。
2/3 只是"常数 ρ 族"的亏空，**不是**信息的价格 —— 这是一个范畴错误，与构造 B 那次自否同一失效模式。

### H-2｜证书覆盖的 ρ 族比"接拒层"实际部署的族**窄**（关键处）

`RegisteredShadowPrice.lambda_for(clock, budget_remaining)` 与 `DynamicPriceCurve.lambda_for_ratio`
都允许价格**随时间/状态变化**。一个分段规则（λ(0) > d_L、λ(δ) ≤ d_H）在该实例上同样拿到 **30 = OPT**。
所以"对所有 ρ"只对**单值、阶段无关**的 ρ 成立；文档从未写明这个限制，却在 §3 直接推广到"接拒层"。

## 4. 复核者给出的"要成为可写进论文的上界，还需补什么"

1. 三行参数化证明（ρ ≤ d_L vs ρ > d_L）+ 显式前提 **`d_H < d_L ⇔ q_L < 2.0476·q_H`**，并用 assert + 非零退出覆盖参数网格；
2. 要么把主张**显式限制**在阶段无关价格，要么扩展到 clock-dependent λ（后者界会消失）；
3. 删掉"信息价格 = 2/3"，或换成真正的**两实例**论证；
4. 提交证书 JSON（或其哈希），常数从 `admission.policies` import；
5. 为 I-1 命题 C 的 6.1/2.05/3 混乱**补勘误**；
6. 撤回"已被独立核对两次"的说法。

**复核者还给了建设性方案**：把构造 C 与 `I₂ = {只有 L}` 配成实例对，确定性策略的最坏情形比值**恰为 1/3**
（接 L：1/3 与 1；拒 L：1 与 0）—— 正是文档已宣称的数字，但此时才是真正的陈述。
注意它会像构造 B 一样**塌掉一半**：随机化策略以 p=1/2 接 L 时给出 1/2，
因此诚实结论应写作"确定性 1/3、随机化 1/2"，**而不是**"2/3 的信息价格"。
