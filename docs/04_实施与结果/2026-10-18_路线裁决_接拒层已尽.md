# 路线裁决记录：接拒层的价格方向已经用尽（2026-10-18）

> 依据总纲 §4.4「选型决策树」的第三条分支：**`L_rule ≈ 0`（规则 oracle 已逼近 causal 最优）⇒ 主推 I-1 + I-3，绝不改写成方法论文**。
> 本记录说明：我们**当前证据落在哪条分支**、还差什么才能确认、以及接下来的动作。

## 1. 证据汇总（全部是接拒层、净价值口径）

| 实验 | 结果 | 结论 |
|---|---|---|
| D4 v1 | `OPT_cl` 2421.07 / `OPT_price*` 2365.42 / `Rule` 2340.05 | 规则已到价格类最优的 **99.0%** |
| D4 v2 | 整数背包 2419.54；时钟相关价格最优 **slope = 0** | 上界没松、时间维度无增益 |
| PF-1 | 温区 λ_k：**+0.00%**；空间×温区 12 参数：**−0.12%** | 温区/空间维度无增益 |
| INV-1 | 三条接拒策略 LOO AUC 0.955–0.972、蒸馏损失 1.6–2.6% | 价值上≈规则，决策上未被完全复现 |
| 阶段 1/1b/1c | 动态 λ −25.75、边际 fw=1 +11.60、fw=5 −10.70（对控制） | 闭环里没有一条跑赢静态规则 |

**合并读法**：在接拒层，价格类只剩 ~1%（`L_rule_clock = 0.99%`），且这 1% **不在**时间/温区/空间任何"场"的方向上（三个维度的实测增益分别 0 / 0 / 负）。

## 2. 裁决

**接拒层（admission、单标量/场价格族）判为"已用尽"**，理由三条：
1. 价格类的类内上界 `OPT_price*` 与当前规则只差 **1%**；
2. 把价格从标量扩成"温区×空间×时间"的场，**三个方向都没有增益**（这是 I-2 叙事的核心机制）；
3. 闭环里任何接拒层改动都会被距离/品质损耗吃掉（阶段 1 已证）。

⇒ 按总纲 §4.4，主线重心应转向：
- **I-1（理论骨）**：信息价格分解 + 不可能性/规则最优性定理；
- **I-3（承载）**：CC-DVRP-3T 基准与协议；
- **I-2 降级**：接拒层价格场记为"已排除的机制族"；**只有**"集合级承诺（OCRS）"与"路由/品质耦合"两半还保留资格，且必须各自过 INV 反演门槛。

## 3. 什么会推翻这个裁决（可证伪条件）

1. **真 causal optimum 显著高于 2365.42**：需要 D4 v3 的 DP/集合级 oracle。如果它比价格类高 ≥3%，说明剩余空间不在价格上，但仍值得做集合级机制 —— 这会支持 I-2 的 OCRS 半边。
2. **路由耦合口径下价格规则失效**：把 net 从 depot 绕行换成真实插入增量后，若 `OPT_price*` 与 `Rule` 的差距扩大到 ≥5%，说明价格需要跟着路线状态变 —— 这会部分复活价格场（但那时它已不是"接拒层价格场"，而是路由耦合定价）。
3. **跨 regime（R1c / R3）出现增益**：当前只在 R1 分布上测过；若 R3（爆发到达）下 λ 场有正增益，需要按 regime 分别裁决。

## 4. 下一步（按优先级）

1. **D4 v3**：在简化设定（单温区、无路线耦合、已知到达分布）下用 DP 求真 causal optimum，给出 `L_future` 的**下界**（当前 2.31% 只是价格类视角的上界估计）。
2. **路由耦合口径的 net**：用 C++ 插入增量替换 depot 绕行，重跑 D4/PF-1（约 1 小时工程量），确认裁决 2 是否触发。
3. **I-1 写作骨架**：把 D4 + PF-1 + INV-1 的证据整理成"信息价格"章节的图表与命题草案。
4. **I-3 基准**：把 `scripts/bench/` 的生成器扩到 R2（Solomon 重标注）并接入四列 oracle。
