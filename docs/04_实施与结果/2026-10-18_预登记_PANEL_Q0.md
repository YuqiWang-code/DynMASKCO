# 预登记：PANEL-Q0（接拒净价值与评测口径对齐测试）

- 日期：2026-10-18
- 类型：**预登记**（正式面板实验）
- 上游：[阶段 1](2026-10-18_阶段1执行记录.md)、[阶段 1b](2026-10-18_阶段1b执行记录.md)、[阶段 1c](2026-10-18_阶段1c执行记录.md)、[D4 v3](2026-10-18_D4v3_因果DP.md)

## 1. 起因（诊断事实，非新假设）

对本仓库冻结评测器 `scripts/evaluation/coldchain_evaluator_a1.py:141-145` 逐行核对，5 日 GATE 面板上五个臂的 `utility` 都精确满足：

```
utility = revenue − 0.1 × distance_km          （reject_loss 实测恒为 0）
```

逐位验证（均值，5 天）：

| 臂 | revenue | distance_km | revenue − 0.1·km | 报告 utility |
|---|---:|---:|---:|---:|
| control_frozen_saa | 1860.0 | 514.7 | 1808.53 | 1808.53 |
| static_price | 1884.0 | 553.5 | 1828.65 | 1828.65 |
| dynamic_dual | 1838.0 | 552.2 | 1782.78 | 1782.78 |
| marginal_gate (fw=1) | 1876.0 | 558.7 | 1820.13 | 1820.13 |
| marginal_gate (fw=5) | 1852.0 | 541.7 | 1797.83 | 1797.83 |

即：**冻结 a1 协议的闭环效用只给收入与距离定价**；品质（Arrhenius / 番茄连续品质）与制冷能耗（C0 预算）进入的是**硬约束**（`fish_unsalable`、`budget_violation`）与**报告量**，不是效用项。

而阶段 1b 起的接拒门控用的是

```
net(i) = REV[c] − fuel_weight · fuel(i) − quality_weight · Q_hat(i)
```

`quality_weight` 一直取默认值 **1.0**。也就是门控在**扣一项评测器并不收费的品质惩罚**，于是系统性过度拒单。

**这可以解释阶段 1/1c/DP 三次"接拒层收益不迁移"**：收益被一个口径外的惩罚抵掉了。

## 2. 假设

H-Q0：在冻结 a1 协议下，把 `quality_weight` 从 1.0 改成 0.0（净价值与评测器口径对齐），
marginal 与 dp 两臂的闭环日效用**都应上升**；且上升幅度应能补上它们与静态 λ 的差距。

## 3. 设定（冻结）

| 项 | 值 |
|---|---|
| 入口 | `scripts/evaluation/run_admission_panel.py` |
| 天数 / 数据 | 5 天 / GATE（与阶段 1 逐字节同配置，仅改 `--quality-weight`） |
| 臂 A | `marginal`，`--quality-weight 0.0 --fuel-weight 1.0` → `results/admission_panel/stage4_marg_q0` |
| 臂 B | `dp`，`--quality-weight 0.0 --fuel-weight 1.0 --dp-npz results/causal_dp/v1/dp_v.npz` → `results/admission_panel/stage4_dp_q0` |
| 对照 | 阶段 1 control 1808.53 / static 1828.65（同配置、同种子，**不重跑**） |

一致性前提：除 `quality_weight` 外与阶段 1/1b 完全一致（同 seed 7003、同 B、同 K、同 time_limit）。若发现任一不一致，判读降级为 `DEVELOPMENT_DIAGNOSTIC`。

## 4. 判据（先冻结）

对每个臂分别判：

| 判定 | 条件 |
|---|---|
| **SUPPORTS-H** | Δ(臂_q0 − 该臂_q1) > 0 **且** Δ(臂_q0 − 控制) > 0 |
| **PARTIAL** | Δ(臂_q0 − 该臂_q1) > 0 但 Δ(臂_q0 − 控制) ≤ 0 |
| **REFUTES-H** | Δ(臂_q0 − 该臂_q1) ≤ 0 |

其中 Δ(臂_q0 − 该臂_q1) = 同臂两版本的 5 日配对均值差；臂_q1 用阶段 1b（marginal fw=1 → 1820.13）与 PANEL-DP（dp）。

附加报告（不参与判定）：`n_served`、`revenue`、`distance_km`、`energy_kwh`、逐日序列、`hard_feasible`、`budget_violated` 计数。

## 5. 止损

- 若某日 `hard_feasible=False`（鱼不可售 / 预算越限）⇒ 该日**仍计入**分母并显式报告，因为 a1 协议把它当硬失败；不得静默剔除。
- 若 90 分钟无 `panel.json` ⇒ `BLOCKED(infra)`，重跑一次。

## 6. 这不能证明什么（预写）

- 只是**口径对齐**实验，不产生新机制；`SUPPORTS-H` 的含义是"我们之前量错了自己"，不是"我们的方法更好"。
- 5 天单集单种子，不足以作统计声明。
- 若 `REFUTES-H`，则"品质惩罚解释了不迁移"这个解释被否掉，需要回到路由/车队瓶颈假说。
- **重要边界**：本实验**不**改变项目对"冷链目标应当给品质与能耗定价"的立场。a1 是冻结的登记协议，为与既有基线可比而保留；CC-DVRP-3T 基准将另行定义含品质与能耗的目标（见总纲 §8.2/§8.3）。两者不可互相替代。
