# 预登记：PANEL-TIER（温区收入分层保留）

- 日期：2026-10-18
- 类型：**预登记**（正式面板实验）
- 上游：[PANEL-Q0 预登记](2026-10-18_预登记_PANEL_Q0.md)（口径对齐）、[阶段 1](2026-10-18_阶段1执行记录.md)、[D4 v3](2026-10-18_D4v3_因果DP.md)

## 1. 起因：三个已核实的冻结事实

这些事实全部来自冻结代码与数据集本身（**不是**从实验结果里挑出来的）：

1. 冻结 a1 评测器的闭环效用是 `utility = revenue − 0.1·distance_km`（`coldchain_evaluator_a1.py:141-145`，`reject_loss` 实测恒 0）。品质与制冷能耗**不进效用**，只进硬约束与报告量。
2. 单一订单收入按温区取常数：`REV = {18°C: 10, 4°C: 20, −18°C: 30}`（`coldchain_evaluator_a1.py:15`）。三类订单的**需求量分布几乎相同**（mean q = 2.02 / 2.00 / 2.00，范围都是 1–3；GATE 集 40 天 × 200 单统计）。⇒ **收入密度相差 3 倍**（4.95 / 10.00 / 15.00 per unit）。
3. 约束侧：15 车 × 50 = 750 总容量，而日均总需求只有 **389.2**（占 51.9%）；日均 194 单，服务时间 0.05 h/单 ⇒ 服务工时 9.7 h，路行 514.7 km ⇒ 17.2 h，合计约 27 h，而车队可供 15×16 = 240 车时。**容量与车时都不紧**。
   同时，控制臂只服务 **107.6 / 194 ≈ 55%** 的订单。

即：**服务能力被"时间窗 + 逐单承诺 + 派车时机"卡住（约束是调度可行性，不是容量），而被拒的订单里混着收入 3 倍于其它类的高价值订单。** 在这种情况下，"把稀缺服务位留给高收入温区"是纯因果规则能拿到的最直接收益；而此前所有机制（静态 λ / 动态对偶 / 边际门控 / DP）都在给**能耗预算**定价，那个资源根本不紧。

## 2. 假设

H-TIER：在冻结 a1 协议下，**按温区收入分层拒绝低价值订单**会显著提高闭环日效用；
最优分层点落在"只接 4°C 与 −18°C"附近。

可通过的强度分级（见 §4）。若 H-TIER 成立，本项目第一次拿到 ≥1.5% 的闭环增益；若被否，说明"服务位稀缺"这个假说错了，瓶颈在时间窗的**时域**而不是**数量**。

## 4. 判据（先冻结）

主指标：5 日配对均值 Δ(变体 − 控制)，副指标 Δ(变体 − 静态 λ = 1828.65)。

| 判定 | 条件 |
|---|---|
| **TIER-WIN** | 某变体 Δ(变体−控制) > 0 **且** Δ(变体−静态) > 0 **且** ≥4/5 天相对控制为正 |
| **TIER-PARTIAL** | Δ(变体−控制) > 0 但 Δ(变体−静态) ≤ 0 |
| **TIER-LOSE** | 所有变体 Δ(变体−控制) ≤ 0 |

同时必须报告：三温区 `service_rate`（若拒绝 18°C 后 −18°C 的服务率没有上升，则机制没有按预期工作，判读降级为 `DEVELOPMENT_DIAGNOSTIC`）、`n_served`、`revenue`、`distance_km`、`hard_feasible` 计数。

## 5. 止损

- 若某变体出现 `hard_feasible=False`（鱼类不可售 / 预算越限）⇒ 该日**计入**分母并显式报告。
- 若 90 分钟无 `panel.json` ⇒ `BLOCKED(infra)`，重跑一次。

## 6. 这不能证明什么（预写）

- 这是**在冻结 a1 口径下**的最优性实验；a1 不给品质与能耗定价，所以 `TIER-WIN` **不能**被说成"冷链感知的接单策略更好"，只能说"在只给收入与距离定价的口径下，按收入密度保留是对的"。
- 5 天单集单种子；`TIER-WIN` 只是候选，需 10 天 + 跨 regime（R1/R1c/R3）复现才谈 Gate。
- 该规则**极其简单**，几乎肯定会被 depth-3 树反演门判为 `RULE_CAPTURABLE` —— 这没关系：它是**基线**（规则 oracle），不是创新点。它的价值是把闭环天花板抬高，让后续机制有可比的强基线。
- 若 `TIER-LOSE`：说明拒掉 18°C 订单并不能换来 −18°C 订单的可服务性（时序不可互换），"服务位稀缺"假说被否。
