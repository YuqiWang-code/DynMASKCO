## 1. 模型与 LP

纯策略恰好两个（`accept_L=0` 与 `accept_L=1`），两实例（A：缺 L；C：两单都在）。
用 B1 打印的比值矩阵（行=策略，列=实例）：

    M = [[0,   1  ],
         [1,   1/3]]

* **上界 LP（随机化最优）**：`max t  s.t.  sum_j x_j M[j][k] >= t  (所有 k),  sum_j x_j = 1, x >= 0`
* **Yao 下界 LP**：`max s  s.t.  sum_k q_k M[j][k] <= s  (所有 j),  sum_k q_k = 1, q >= 0`
  （即对上式转置后的同一个博弈值；若两者相等则紧）

## 3. 顺带发现：来源笔记里的 LP 写反了

`theorem_paths` 里写的是 `min t s.t. sum_j x_j ALG >= t OPT`，但**最小化 t 会得到 −inf**
（约束是 payoff ≥ t，t 越小越容易满足）⇒ 正确的形式是 **max t**。
照原文实现会直接得到 t→−inf 或 t=0 的假结果（我第一版就是照抄，输出 0）。
这与摘要标出的另一处矛盾（`max_j max_k` 与"每列最大再取最小"）同源：**该笔记在"取最大/取最小"上有系统性笔误**。
