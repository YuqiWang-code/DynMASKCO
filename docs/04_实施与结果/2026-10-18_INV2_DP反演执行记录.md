## 1. 为什么要做 INV-2

INV-1 已把静态 λ、动态对偶、学习型线性三条策略送去反演，三条都 `NOT_CAPTURED` 但"价值上几乎等价于 depth-3 树"⇒ 按裁决**降级为基线**。

D4 v3 加入的新策略 `dp_threshold`（状态依赖的预算阈值）在接拒层取得 +1.45%（5/5 天）。按总纲 §1.2，**任何要升为主线的策略必须先过反演门**：若 depth-3 树能以 >0.98 AUC 复现它、且蒸馏后效用损失 <5%，则说明它的价值可以被一个规则吸收 ⇒ `RULE_CAPTURABLE` ⇒ 降级。

所以 INV-2 是 DP 分支的准入检查，不是新实验。

## 2. 判据（继承 INV-1，未改动）

- `RULE_CAPTURABLE` ⇔ `LOO AUC(depth-3 tree) > 0.98` **且** 效用损失 `< 5%`（合取）
- 否则 `NOT_CAPTURED`
- 特征集、树深、LOO 协议、净价值口径与 INV-1 完全一致

**诚实标注**：DP 臂是在 INV-1 跑完后**追加**到同一 harness 的，判据是继承的、不是为 DP 新写的。严格说这是"带固定继承判据的探索性复核"，不是新预登记。此处如实写明，不把它包装成预登记实验。

## 3. 结果（服务器 `fd2e23ca`，1000 条决策日志）

| 策略 | n | 接受率 | LOO AUC(depth-3 tree) | net(原策略) | net(树蒸馏) | 损失 | 判定 |
|---|---:|---:|---:|---:|---:|---:|---|
| `static_lambda` | 1000 | 0.742 | 0.9554 | 11781.7 | 11475.2 | +2.6% | **NOT_CAPTURED** |
| `dynamic_dual_eta0.02` | 1000 | 0.749 | 0.9724 | 11968.5 | 11775.7 | +1.6% | **NOT_CAPTURED** |
| `learned_linear_v2` | 1000 | 0.732 | 0.9674 | 11781.7 | 11580.5 | +1.7% | **NOT_CAPTURED** |
| `dp_threshold` | 1000 | 0.743 | **0.9732** | 11932.1 | 11753.1 | **+1.5%** | **NOT_CAPTURED** |

（前三行与 INV-1 记录逐位一致，说明 harness 改动没有动到旧臂；本表是同一 harness 的完整四臂。）

## 4. 读法

1. **DP 过反演门**：AUC 0.9732 < 0.98 ⇒ 合取判据的第一项不满足，`NOT_CAPTURED`。DP 的决策**不能**被 depth-3 树以要求的保真度复现。
2. **但差距很小**：0.9732 距 0.98 只差 0.0068，且损失仅 1.5%。这与 INV-1 的结论形状一致——三条旧策略的 AUC 落在 0.955–0.972，DP 只把 AUC 抬了 0.001（相对动态对偶）。
3. **AUC 不是价值**：四臂的 AUC 与净价值排序**不一致**（AUC 最高的 DP 是 0.9732，净价值最高的也是 DP 11932.1；但 `learned_linear_v2` 的 AUC 0.9674 高于 `static_lambda` 的 0.9554，净价值却**完全相同** 11781.7）。这说明"树能多好地预测决策"与"决策值多少钱"在本设定下是弱耦合的。
4. 因此 INV-2 的结论是：**DP 不被规则吸收，保留为主线候选**；但"DP 比动态对偶强"这件事的幅度很小（11932.1 vs 11968.5，DP 反而**低** 36.4），在 1000 条日志的表级口径下不构成 DP 优越性的证据。

> 注意第 4 点与 D4 v3 的关系：D4 v3 里 DP 是 2399.64 vs 最优固定价格 2365.42（+1.45%），**DP 赢**；本表里 DP 净价值 11932.1，动态对偶 11968.5，**DP 略输**。两者口径不同（D4 v3 是 5 日 GATE 的日效用聚合，本表是 1000 条决策日志的净价值），**不能混读**。真正决定去留的是全仿真面板，即 [PANEL-DP 预登记](2026-10-18_预登记_PANEL_DP.md)。

## 5. 这不能证明什么

- depth-3 树不是唯一的规则假设类；更深的树、GBDT、或带预算状态的树可能把 DP 吸掉。`NOT_CAPTURED` 只对**冻结的**假设类成立。
- 本表 1000 条日志来自单一 GATE 集，AUC 的 0.0068 余量远小于跨集波动，**不能**声称"DP 稳定不可捕获"。
- 反演门的目的是防止"用复杂方法重造一个已有规则"，它**不**证明 DP 有正面价值；那要 PANEL-DP 回答。
