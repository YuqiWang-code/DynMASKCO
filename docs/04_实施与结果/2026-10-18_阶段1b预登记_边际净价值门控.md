# 阶段 1b 预登记：边际净价值门控（距离 + 品质进判据）

> 登记时间：2026-10-18 12:20（**先于执行**）｜ 类型：开发面板（DEVELOPMENT_PANEL）+ 预登记判据
> 起因：阶段 1 判 `DOMINATED`（动态 λ − 控制 = −25.75），机制诊断指认"只按收入预留预算"会把钱花在**距离长、品质损耗大**的订单上。本阶段把**边际距离**与**边际品质损耗**直接写进接拒判据。

## 1. 假设（可证伪）

> **H1c**：把判据换成边际净价值 `net(i) = REV[c] − 0.1·km_hat(i) − Q_hat(i)` 后，相对**冻结 SAA 控制臂**的逐日效用配对差均值为正，且非零改进天 ≥ 3。

若不成立（均值 ≤ 0 或非零天 ≤ 2）→ 记 `DOMINATED`/`MECHANISM_NULL`，转联合耦合方向，不再在 η/权重上调参。

## 2. 判据定义（跑之前固定）

```
km_hat(i)   = KM_PER_UNIT × min_{v,pos} [ d(a,i) + d(i,b) − d(a,b) ]      # a,b 为当前计划里的相邻节点
Q_hat(i)    = PVAL[c] · q_i · (1 − exp(−K_EFF[c] · dwell_h))
dwell_h     = 2 · Δunits / (SPEED_KMH / KM_PER_UNIT)                       # 往返绕行带来的在车时间
e_lower(i)  = q_i · 0.15 · (25 − T_target[c])                              # 登记预冷口径
接受  ⟺  net(i) − λ(clock) · e_lower(i) > 0
```

- `λ(clock)`：**登记静态规则**（与阶段 1 的 static 臂同一张表），不在本阶段重调。
- `PVAL/K_EFF/SPEED/KM_PER_UNIT/FUEL_COST_PER_KM`：全部取 `run_exp_reserve` 的登记常量。
- 权重：`fuel_weight = quality_weight = 1.0`（不做扫描）。
