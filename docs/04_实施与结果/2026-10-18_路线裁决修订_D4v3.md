# 路线裁决修订（D4 v3）：因果头空间存在，但不在"价格场"里

> 本记录**追加**在 [`2026-10-18_路线裁决_接拒层已尽.md`](2026-10-18_路线裁决_接拒层已尽.md) 之后，
> 按项目纪律：不改写旧记录，只追加修订与适用范围。

## 1. 为什么要修订

D4 v3（简化设定 DP）给出：

| 策略 | GATE 净价值 | 相对 DP |
|---|---|---|
| DP 状态依赖阈值 `λ_t(b)` | **2399.64** | 1.000 |
| 最优固定价格 λ\* | 2365.42 | 0.986 |
| 登记固定价格规则 | 2340.05 | 0.975 |
| 预知整数背包（上界） | 2419.54 | 1.008 |

→ **状态依赖策略比最优固定价格高 1.45%，比登记规则高 2.50%，且 5/5 天同向。**
→ 预知上界只比 DP 高 **0.89%**。

## 2. 修订后的表述（精确版）

**旧裁决保留的部分**：
- 温区/空间/时间的**固定价格场**无增益（PF-1：+0.00% / −0.12%；D4 v2：时间斜率 0）；
- **固定价格类**内只剩 ~1%（D4 v1/v2）。

**新裁决新增的部分**：
- 接拒层**有**因果头空间（≈1.5–2.5%），来源是**状态依赖**（剩余预算 × 剩余步数的值函数），不是"更细的价格"；
- 未来信息本身价值很小（≈0.9%），这意味着**"因果信息价格"这个卖点的主要部分不是"未来信息贵"，而是"状态依赖非平凡"**。

## 3. 对总纲三条主线的影响

| 主线 | 修订后判断 |
|---|---|
| **I-2（λ 场 + OCRS）** | 部分复活：不是"温区/空间场"，而是 **budget-state × time 的值函数阈值**（DP 近似）。需在闭环验证 + 过 INV 门槛 |
| **I-1（信息价格）** | 叙事要改：未来信息只值 ~0.9%，不能把"未来信息价格"当主卖点；应改为"**因果策略的状态依赖价值**" |
| **I-3（基准）** | 不受影响，继续 |

## 4. 立即执行（下一轮）

1. `λ_t(b)` 策略在接拒层复现（与 D4 v1 同口径）→ 若复现 1.45%，写预登记。
2. 全仿真 `DPThresholdReplanner`（5 天受控 A/B）→ 看 `utility` 是否保住。
3. INV 反演：用 12 维（含 budget_ratio × seen 交互）浅树复现 DP 决策 → 判是否规则可捕获。
4. 若闭环为正 → 这是本项目第一个**有机制的**正增益候选；若闭环为负 → 记"状态依赖阈值也被距离/品质吃掉"。

## 5. 不主张

- 不声称"D4 v3 的 1.45% 就是可发表增益"：单资源、i.i.d.、5 天、n=5。
- 不声称 DP 是原问题最优：它只是单资源简化设定的 causal optimum。
- 不推翻旧记录：旧记录在"固定价格场"范围内仍然有效。
