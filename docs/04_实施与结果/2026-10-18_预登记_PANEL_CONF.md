# 预登记：PANEL-CONF（拒因保形：密度阈值 + 覆盖保证）

- 日期：2026-10-18
- 类型：**预登记**（正式面板实验；I-2 机制族的最后一项）
- 上游：总纲 §4.2(5)、[路线裁决（接拒层关闭）](2026-10-18_路线裁决_接拒层关闭.md) 第 3 条

## 1. 先讲清一件事：保形在这个问题里**不是独立机制**

I-2 的第三半"拒因保形"要解决的问题是"阈值没控制真正的拒因风险"。但在冻结 a1 协议下，
接拒层的判定形状只有一种：**`accept ⟺ REV[c] / e_lower(c,q) ≥ ρ`**（收入密度阈值）。
静态 λ 是 ρ = λ\* = 2.25；在线背包是 ρ = φ(z)（随时间变）；保形给的 ρ 只是**另一个选法**：

```
ρ_α = TRAIN 上密度的第 ⌈(n+1)(1−α)⌉ 个次序统计量        （split-conformal，有限样本）
```

于是保形带来的是**覆盖保证**（`P(d_new ≥ ρ_α) ≥ 1−α`），**不是**新的作用机制。
「阈值怎么选」这件事已被 [D4 v1](2026-10-18_D4v1_信息价格分解.md) 用 λ 网格 + 离线最优覆盖过：
最优固定 ρ = 2.25 时规则已达价格类最优的 **99.0%**。

**所以本实验的定位是"把机制族关干净"，不是"再赌一次 Gate"。** 这一点先说清楚，避免事后把负结果说成意外。

## 2. 标定结果（在 GATE 上跑之前算好，冻结）

TRAIN = `RR.generate_dataset(200, 200, 20260925)`，n = 38675 个订单，密度 `d = REV[c]/e_lower`：

| α | ρ_α | 次序统计量 | `frac(d ≥ ρ_α)` | 说明 |
|---:|---:|---:|---:|---|
| 0.40 | 3.7934 | 23205 | 0.4000 | — |
| 0.50 | **3.4216** | 19338 | 0.5000 | 本实验臂 A |
| 0.70 | **2.6320** | 11603 | 0.7000 | 本实验臂 B |
| — | 2.25 (=λ\*) | — | ≈0.78（反推） | 静态 λ 等价于 α ≈ 0.78 |

密度分布：min 1.55 / median 3.42 / max 9.52（与 `REV = 10/20/30`、`e_lower ∝ q·ΔT` 的定义域一致）。

**注意**：α = 0.5 与 0.7 给出的 ρ **都高于** λ\* = 2.25 ⇒ 两个保形臂都比静态 λ 更挑剔，
会系统性地拒掉 −18 °C 订单（密度 2.33）。

## 3. 假设

H-CONF（等价性 + 不优于最优固定阈值）：

1. 在冻结 a1 协议下，保形密度阈值与静态 λ 属于**同一判定族**，因此
   `Δ(conf − 静态 λ) ≤ 0`（静态 λ 是该族的最优代表，已在 TRAIN 上调到最优）。
2. 由于 ρ_α > λ\*，两个保形臂还会**低于控制**：`Δ(conf − 控制) < 0`。
3. 覆盖核对应通过：GATE 上 `frac(d ≥ ρ_α)` 与名义 `1−α` 的偏差在有限样本波动内（±0.05）。

## 4. 设定（冻结）

```bash
python scripts/evaluation/run_admission_panel.py --days 5 --arms conf \
    --conf-alphas 0.5,0.7 --out results/admission_panel/stage6_conf
```

## 5. 判据（先冻结）

| 判定 | 条件 |
|---|---|
| `CONF-EQUIVALENT` | 两臂都 `Δ(臂−静态) ≤ 0` **且** 覆盖核对通过（\|frac − (1−α)\| ≤ 0.05） |
| `CONF-UNEXPECTED` | 任一臂 `Δ(臂−静态) > 0`（与等价性假设矛盾，需查是否保形选到了更好的 ρ） |
| `CONF-COVERAGE-FAIL` | 覆盖核对偏离 > 0.05（说明 TRAIN→GATE 分布漂移，标定不可迁移） |

## 6. 这不能证明什么（预写）

- 不证明"保形预测在在线路由里没用"：本实验只测了它作为**阈值选择器**的那一面。
  保形真正可能有用的是**预测插入成本的上界**（conformalized insertion cost），那需要先记录
  "预测绕行 vs 真实绕行"的配对样本，本仓库尚未记录该序列 —— 已记入 I-3 的待办。
- 不证明 α 网格选完了：只测了 0.5 / 0.7。但 `Δ ≤ 0` 的结论若成立，与 D4 v1 的"最优固定 ρ 已找到"一致，
  再加 α 也只是重复同一族。
- 5 天单集单种子。
