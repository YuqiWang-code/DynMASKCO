# D4 v1 执行记录：信息价格分解（接拒层）

> 代码：`scripts/evaluation/run_information_price.py`（commit `683bf7c3`）｜ 产物：`results/info_price/v1/info_price.json`
> 运行：服务器 `MASKCO_v1`，Python 3.10 / numpy 2.2.6，**~2 s**；本地同一 commit 逐位一致（同数值）

## 1. 三个量与两个分解（定义先写死）

| 量 | 定义 |
|---|---|
| `OPT_cl` | **完全预知**的分数背包上界（允许切分订单，逐日） |
| `OPT_price*` | **价格规则类最优**：在 TRAIN 200 天上网格选一个**与时钟无关**的固定 λ\*，再用到 GATE 5 天（非预知） |
| `Rule_now` | 登记静态规则（λ 随 clock 变化，来自 TRAIN 校准表） |

```
L_future_price = (OPT_cl − OPT_price*) / OPT_cl        # 预知能拿到、价格类拿不到
L_rule_price   = (OPT_price* − Rule_now) / OPT_price*  # 价格类内，当前规则还差多少
```

## 2. 结果（GATE 5 天，净价值口径）

| 量 | 值 |
|---|---|
| `OPT_cl`（分数背包，预知） | **2421.07** |
| `OPT_price*`（TRAIN 选 λ\*=2.250） | **2365.42** |
| `OPT_price`（GATE 事后最优 λ） | 2365.42（与 TRAIN 选出的 λ\* 相同） |
| `Rule_now`（登记静态规则） | **2340.05** |
| **`L_future_price`** | **2.31%** |
| **`L_rule_price`** | **0.99%** |
| `Rule_now / OPT_price*` | **0.990** |

## 3. 这张表最要紧的一句话

> **在接拒层，价格规则几乎已经到顶**：一个 TRAIN 选出的固定 λ\* 就能拿到价格类最优的 100%，登记规则已到 **99.0%**；真正拿不到的只有相对"预知"的 **2.31%**。

这条结论同时解释了三件事：

1. 为什么阶段 1/1b/1c/学习型 λ 都只能在 ±1–2% 里打转 —— **价格类的天花板就在 1% 附近**；
2. 为什么 INV-1 反演显示"价值上≈规则" —— 因为整个价格族都挤在同一条边界上；
3. 为什么总纲坚持 SOTA 必须来自**路由/品质耦合与集合级承诺**（I-2 的 λ 场只有跨越"容量×能量×品质"的联合约束才可能突破，单标量价格不行）。

## 4. 诚实边界（这一版只能这样读）

1. `OPT_cl` 是**分数背包**（允许切分订单），是松上界；整数背包会更紧，`L_future_price` 会变小。
2. `OPT_price*` 只是**价格规则类**的上界，不是全空间 causal optimum。所以：
   - `L_future_price` 是"未来信息占比"的**偏大**估计；
   - `L_rule_price` 是"当前规则还能改多少"的**偏保守**估计。
3. 净价值的燃油/品质用 **depot 往返绕行**近似，不含真实路线耦合与时间窗；全仿真 `utility` 口径下这两个百分比会变（可能变大也可能变小）。
4. 5 天、单 seed、n=5；不做显著性。
5. λ\* 在 TRAIN 上选，但 TRAIN 只有 200 天且与 GATE 同分布；跨分布（R3/R2）未测。

## 6. v2 追加（2026-10-18 晚）：更紧的上界 + 更大的价格类

同一脚本新增两项，结论**没有变**：

| v2 量 | 值 |
|---|---|
| `OPT_int`（0/1 背包，0.01 kWh 离散化） | **2419.54** |
| `OPT_clock`（TRAIN 网格选 λ(t)=λ0+slope·t/H） | **2365.42**（λ0=2.250，**slope=0**） |
| **`L_future_integer`** = (OPT_int − OPT_clock)/OPT_int | **2.25%** |
| **`L_rule_clock`** = (OPT_clock − Rule)/OPT_clock | **0.99%** |
| `Rule / OPT_clock` | **0.990** |

读法：

1. 分数背包与整数背包几乎同值（2421.07 vs 2419.54，差 1.5）⇒ 上一版的松弛**没有明显夸大** L_future。
2. 把价格类从"常数 λ"扩到"λ 随 clock 线性变化"后，TRAIN 选出的最优**斜率恰好为 0** ⇒ 时钟相关价格**没有带来任何增益**，价格类确实到顶。
3. 因此 `L_rule ≈ 1%`、`L_future ≈ 2.3%` 是稳健的（在接拒层、本成本口径下）。

局限不变：仍是 table-level 净价值（depot 绕行估计燃油/品质），不含路线耦合与时间窗；5 天、单 seed。
