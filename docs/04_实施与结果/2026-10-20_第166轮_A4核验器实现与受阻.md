单测输出（本地）：

```
slack  q=25.0000  PASS        # 预算宽松：接受有利（30 − 0.25×10 − 挤出 2.5）
tight  q=-70.0000  PASS       # 预算仅剩 10 kWh、未来有 30 元/10 kWh 的单 ⇒ 机会成本占优 ⇒ 拒
nolook ahead ΔU=1.0000 == revenue-lam*e=1.0000  PASS   # 无未来订单时退化为 static 阈值
```

机制说明（一句话）：`static` 只看单步 `revenue − λ·e_hat > 0`；`verifier` 把「本单占掉的预算
挤掉了未来哪一单」用 N 条训练集拟合的未来到达流展开算成 `ΔU` 分布，取 25% 分位判正。
因果性：rollout 只读 (当前订单, clock, 剩余预算, 训练历史采样流)，不读 `env` 的任何未来项。
