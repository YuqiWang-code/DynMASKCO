# 预登记 PF-1：温区影子价格场（λ 随温区变化）能否超过单标量价格？

> 登记时间：2026-10-18（**先于执行**）｜ 依据：总纲 §3.1①「温区影子价格是时刻表而不是单标量」、§4.2 I-2
> 这是对 I-2 核心主张的**接拒层最小检验**：同一单位电量在三温区之间不能自由替换 ⇒ 价格应当依赖温区。

## 1. 假设（可证伪）

> **H-PF1**：把价格从单标量 λ 扩成"每个温区一个价格" λ_k（k ∈ {18℃, 4℃, −18℃}）后，GATE 5 天的净价值比**最优单标量** λ\* 高出 **≥ 1%**。

若 ≤1% ⇒ 温区维度**在接拒层不可用**，I-2 只能靠空间/时间或集合级承诺，不得再以"温区价格场"作为卖点。

## 2. 唯一变化因素

- 相同数据（TRAIN 200 天 / GATE 前 5 天）、相同预算 B=710.6548328611384、相同净价值口径（`REV − 燃油 − 品质`，depot 绕行估计）、相同接受规则 `net − λ·e > 0` 与预算硬闸。
- **只变价格结构**：单标量 λ → 三元组 (λ_0, λ_1, λ_2)。

## 3. 冻结设置

| 项 | 值 |
|---|---|
| 价格网格 | {0.75, 1.0, 1.25, …, 5.0}（步长 0.25，共 18 档） |
| 选择方法 | **坐标上升**（从最优标量 λ\* 出发，逐类在网格上取最优，2 轮），只使用 TRAIN |
| 评估 | GATE 5 天，逐日净价值 + 均值 |
| 对照 | ① 最优单标量 λ\*（D4 v2 已得 2.25）；② 登记静态规则（λ 随 clock）；③ 整数背包上界 `OPT_int` |
| 判据 | `mean_net(λ_k) / mean_net(λ*) − 1 ≥ 1%` ⇒ **PASS**；否则 **DOMINATED** |

## 4. 分母与止损

- 分母 = GATE 5 天全量；不筛天、不剔异常。
- 止损：若三元组里至少两类的价格被选到网格下界（0.75）或上界（5.0），视为"该维度无分辨力"，直接记 `MECHANISM_NULL`，不再扩网格。

## 5. 不主张

1. 接拒层净价值 ≠ 闭环 `utility`；本检验只是一票否决的第一步。
2. 与 D4 的 `OPT_int` 比较时，`OPT_int` 是**预知**上界，不参与"是否超过"的判定，只作参考。
3. 5 天、单 seed、n=5；不构成显著性。
4. 若 PASS，也**不能**直接声称闭环有增益——必须另登记全仿真面板。
