## 2. 这一轮新拿到的三条独立负证据

这三条是本轮（第 6 轮）一次性补齐的，它们把"I-2 还有两半没试"这个退路也关掉了：

### 2.1 DP 状态依赖阈值：表级 +1.45% → 全仿真 −3.50%（符号翻转）

| 口径 | DP | 对照 | Δ |
|---|---:|---:|---:|
| 表级（D4 v3，5 天 GATE 净价值） | 2399.64 | 2365.42（最优固定价） | **+1.45%**（5/5 天） |
| 全仿真（PANEL-DP，5 天日效用） | 1745.32 | 1808.53（控制） | **−3.50%**（1/5 天为正） |

且反演门判 `NOT_CAPTURED`（AUC 0.9732 < 0.98）⇒ 它不是"被规则吸收"，而是**表级状态空间本身漏掉了真瓶颈**。

### 2.2 温区收入分层：五个变体全负（两种极性都试了）

`T12 / T2 / T12L / T0` 全部 ≤ 控制 − 8%，最差 −70%。机制上找到原因：
控制臂的三温区服务率已经是 `0.708 / 0.597 / 0.312`，即"按能耗效率排序"系统自己做了；
拒掉一类**换不来**另一类的服务率成比例上升（负交互：`T12` 里 4 °C 服务率从 0.597 掉到 0.410）。

### 2.3 接拒净价值里的品质项数值惰性

`quality_weight` 从 1.0 改到 0.0，5 天轨迹**逐位相同**（Δ = 0.00）。
量级核算：`Q_hat ≈ 1.3e−3`，而参与比较的 `REV − λ·e_lower ≈ 1…6` ⇒ 品质项小 3–4 个数量级，
**从未参与过任何一次判定**。也就是说前几轮所谓"冷链感知影子价格"实际只有"收入 vs 预冷能耗"在起作用。

## 3. 裁决

1. **关闭接拒层机制族**（λ 场 / 动态对偶 / 边际门控 / DP 状态依赖 / 温区分层 / 在线背包阈值）。
   理由：按总纲 §11.3 的止损纪律，多个机制已连续两轮 `DOMINATED`，且两种排序极性、三个资源维度
   （时间 / 温区 / 空间）、状态依赖与非状态依赖两路都已测过，全部不迁移。
2. **不再调 `quality_weight`。** 它没有信号（PANEL-Q0 精确 0）。
3. **I-2 降级为"已排除的机制族"**，并作为**有价值的负面证据**写入论文（总纲 §4.4 分支 2/3 都允许这么处理）。
   `OCRS` 与 `拒因保形` 两半**在关闭前各跑一次**（已在 [PANEL-OKP 预登记](2026-10-18_预登记_PANEL_OKP.md) 中启动、
   保形待第 7 轮），以满足"机制族要么被证否、要么被测量"的纪律；但**不再为它们追加轮次**。
4. **主线锁定 I-1 + I-3**：
   - **I-1**：两个参数化不可能性构造 + 规则 oracle 的最优性定理；
   - **I-3**：CC-DVRP-3T 严格因果基准（数据半边已达成 G2-a）、12 条基线、四列 oracle、指标与 leaderboard。
5. **G4 记为 `NOT MET`**（当前 5 天 +1.11%，未达 1.5%）；10 日面板作为确认证据补齐后只追加，不改判定。

## 4. 这个裁决**不**主张什么

- 不主张"冷链在线路由没有可研究的在线算法"：本裁决只针对**冻结 a1 协议**（`utility = revenue − 0.1·distance`，
  品质与能耗仅作约束）。在一个把品质与制冷能耗写进目标的口径下，温区与能耗的经济学会变，结论必须重测——这正是 I-3 要做的事。
- 不主张"I-2 在理论上不可能"：`OCRS` 的**集合级** contention resolution 在"逐单不可撤销"的冻结协议里
  **不可表达**（`StrictOnlineEnv` 在订单 reveal 时刻就要求终局决定）。要说 OCRS 无效，必须先改协议支持"可延迟承诺"。
  本裁决只能说：**在当前协议下**，它的可表达子族被测量且为负。
- 不主张"我们的负结果已经是论文级结论"：它们通过了预登记与完整分母，但仍是单集、单种子、5 天，且未经独立复核。
