# 第二次"外部重排"失败：**跨车 reassignment 也破不变量** ⇒ 3.47× 只能从规划器内部关闭

- 日期：2026-10-18（继续迭代，第 86 轮）
- 类型：**BLOCKED（第二次）+ 结构结论**
- 代码：`scripts/admission/panel_replanner.py::PartitionReoptReplanner`（臂名 `part`）
- 上游：[同集合 2-opt = 0](2026-10-18_同集合2opt_零差异.md)、[OR-Tools 路线臂 BLOCKED](2026-10-18_G2_OR-Tools路线臂_BLOCKED.md)

## 1. 做了什么

按第 85 轮的结论（余量在**车辆-订单分配**而非顺序），实现 `PartitionReoptReplanner`：

1. 取"已接受但未服务、且不在任何 suffix 中"的订单为待派池；
2. 按 `tw_end` 升序（最紧先排）；
3. 对每辆 **idle 且从仓库出发**的车贪心装满（容量 + TW 逐单校验）；
4. 写回 `mutable_suffix`。

刻意限制"只动 idle 车、不动已提交前缀、逐单校验"，以避免 OR-Tools 那次的失效模式。

## 2. 结果：仍然不可行

| 量 | 值 |
|---|---:|
| utility | **137.15** |
| 收入 / 里程 / 服务单 | 150 / 128.5 km / **7** |
| 能耗 | **715.3**（预算 710.65） |
| `hard_feasible` | **False** |
| failure tags | **`budget_violation`, `duplicate_service`** |

服务单从 94 崩到 7，并出现 `duplicate_service`（同一订单被服务两次）。

## 3. 两次外部干预的对照：同一类失效

| 干预点 | 结果 | 失效标签 |
|---|---|---|
| OR-Tools **替换路线** | utility 2339 但能耗 1186.8 / 710.65 | `budget_violation`, `commitment_violation`, `served_not_accepted`, `accepted_not_delivered` |
| 自研**跨车重新分配** | utility 137 且服务单崩到 7 | `budget_violation`, `duplicate_service` |

两者都在**同一个位置**断开：**能耗/承诺/去重的记账都写在 `SaaReplanner` 的规划路径里**。
只要绕开它去改 suffix，这些不变量就失去维护者——即使我逐单校验了容量与 TW。

## 4. 由此得到的结构结论（这是本轮真正的产出）

> 在冻结环境里，"路线/分配的质量"与"能耗-承诺-去重约束"是**同一个规划器的两个不可分离面**。
> 任何从外部后处理路线或分配的尝试都不可行（已两次实测）。
> 因此 **3.47× 的里程余量只能通过"重写规划器"来关闭**，而不能通过在 SAA 外面套一层优化器。

这条结论同时解释了两件事：
1. 为什么"外部强基线"很难进这个协议（不是求解器不行，而是记账在被替换的那一层）；
2. 为什么 `batched_dispatch`（在 SAA **内部**只改派车时机）能拿到 +4.44% 而外部重排全崩
   —— 前者保留了记账，后者破坏了记账。

## 5. 对 G2/G4 的影响

- **G2**：OR-Tools/PyVRP 若要以"路线求解器"身份进入，**必须**先重写环境的预算记账（超出基线接入范围）。
  可行的替代形式是"**同集合 2-opt**"（已实现：结果 = 0）或"**同集合重排 + 环境复检**"（同样 0）。
  因此 G2 的外部基线只能以 **admission-filter**（如 PyVRP 可行性判定，已实现但 0 拒绝）或
  **离线对照**（如 `route_reopt_pyvrp.py` 的预知上界）形式存在。
- **G4**：不要再尝试"外壳优化路线"。要动 3.47×，只能 **从零写一个维护全部不变量的 replanner**
  （见 [构造器计划](2026-10-18_计划_构造器接入闭环.md) 的步骤 3–5），这是一个真正的工程量。

## 6. 这不能证明什么

- 不证明 3.47× 不可关闭：只证明**外部后处理**这条路不可行；
- 不证明环境设计有错：记账放在规划器里是合理设计，只是让"外部替换"变得不可能；
- 本轮的 `part` 臂**不进入排行榜**（不可行解）；
- 单日、单集单种子。
