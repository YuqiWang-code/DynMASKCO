## 1. DP 定义

```
V_0(b) = 0
V_t(b) = E_type[ max( V_{t-1}(b),  m + V_{t-1}(b − e) ) ]     (e ≤ b)
```

`V_t(b)` = 剩余 t 步、剩余预算 b 时的最大**期望**净价值。该值是该简化设定下**任何非预知策略**的期望上界。
策略形式（由 DP 导出）：接受 ⟺ `m + V_{t-1}(b−e) ≥ V_{t-1}(b)` —— 即**状态依赖阈值** λ_t(b)（随剩余预算与剩余步数变化，且对 e 非线性）。

## 3. 这条结果改变了什么（重要）

上一轮裁决（[`2026-10-18_路线裁决_接拒层已尽.md`](2026-10-18_路线裁决_接拒层已尽.md)）说"价格方向已用尽"。D4 v3 表明这句话需要**收窄**：

| 说法 | 现在是否成立 |
|---|---|
| "温区/空间/时间**价格场**没有增益"（PF-1 + D4 v2） | ✅ 仍然成立 |
| "价格类只剩 ~1%"（D4 v1/v2） | ✅ 仍成立（但只针对**固定价格类**） |
| "接拒层没有因果头空间" | ❌ **不成立**：状态依赖策略比最优固定价格高 **1.45%**、比登记规则高 **2.50%** |
| "未来信息价值很大" | ❌ 不成立：预知上界只比 DP 策略高 **0.89%** |

**新结论**：
1. **未来信息的价值很小（≈0.9%）**，之前 D4 v1 的 2.31% 是"价格类视角"的偏大估计；
2. **真正的头空间在"状态依赖"**——同样的信息、同样的分布，把阈值写成 `λ_t(b)`（剩余预算 × 剩余步数）就能拿到 +1.45%/+2.50%；
3. 这与总纲 I-2 的原意一致（λ 是"时刻表"而不是标量），但**不是** PF-1 测的那种"温区/空间场"，而是**预算-时间状态函数**。

## 4. 诚实边界

1. **i.i.d. 假设**：DP 用 TRAIN 经验分布，GATE 同分布 ⇒ 对本题公平，但真实订单非平稳，需另测。
2. **单资源**：只有能耗，没有路线耦合/时间窗/车队；闭环 `utility` 下增益会被距离与品质损耗吃掉（阶段 1 已见）。
3. **实现值 vs 期望值**：DP 策略 GATE 实现 2399.64 略高于期望 2386.99（5 天采样波动），不是"DP 超过自身上界"。
4. **离散化**：0.25 kWh；更细会略高。
5. n=5、单 seed；`+1.45%` 不构成显著性，但 5/5 天同向是可复现的机制信号。
6. 预知整数背包 2419.54 仍是**松弛上界**（单资源口径），不是原问题最优。
