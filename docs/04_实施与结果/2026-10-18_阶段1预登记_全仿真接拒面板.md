## 3. 主指标与次指标

**主指标**：逐日 `utility` 配对差 `Δ = utility(C) − utility(A)`，报告 5 天的符号、均值、中位数、符号检验（n=5）。

**次指标**：
1. `Δ' = utility(C) − utility(B)`（相对本方静态 λ 的增量，用于归因"动态"而非"过滤"）。
2. 预算利用率（`energy_kwh / B`）与接受单数、`n_served`。
3. λ 轨迹（每日 12 点摘要）与拒绝原因分布（`below_shadow_price` / `over_remaining_budget`）。
4. 可行性：三臂的 `hard_feasible`、`budget_violated` 必须全 0/FALSE。

## 4. 判定规则（机械）

| 观察 | 判定 |
|---|---|
| 均值 Δ > 0 且非零改进天 ≥ 3，且可行性全过 | `LEAD`：另登记 40 天阶段 |
| 均值 Δ > 0 但非零天 ≤ 2 | `MECHANISM_NULL`：动态 λ 只在小部分天起作用，转联合耦合方向 |
| 均值 Δ ≤ 0 | `DOMINATED`：按方案文档转"联合时间窗×车队耦合"，如实记负结果 |
| 任一臂出现 `hard_feasible=False` 或 `budget_violated=True` | `INVALID`：先修工程，不判科学 |

## 5. 分母与排除

- 分母 = **5 天**（登记 `day_indices=[0,1,2,3,4]`）；**不剔除**任何天，不按结果选天。
- 若某天产生 `None` 效用：保留在分母里并记为失败（不静默丢弃）。

## 6. 不主张（写进结果）

1. n=5，符号检验最多给出 p≈0.03（5/5）或 0.0625（4/5），**不构成显著性或正式增益**。
2. 单面板、单 η；结论只覆盖"这 5 天 + 这套超参"。
3. 与 `+25.54` 的旧线索不可直接比较（旧线索用登记静态规则，本面板的 B 臂是它的复现，A 臂是冻结 SAA）。
4. 不声称超过 OR-Tools/任何外部基线。
