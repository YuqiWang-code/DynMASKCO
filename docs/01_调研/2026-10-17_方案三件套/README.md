## 三份文档的共同诊断（我们据此排序工作）

1. 瓶颈不在路由算术，而在**「哪些订单值得消耗当天能量预算」**：预算是被动校验，而不是按"每 kWh 收入"排序的稀缺资源。
2. 现有 `+25.54` 的结构（`[0, +102.92, +24.76, 0, 0]`）说明静态排序只在预算恰好紧张时起作用 ⇒ 静态 λ = 固定影子价格，是间隙的数学本质。
3. 正确的下一步是**让 λ 随剩余预算在线变化**，并把"是否接受"从仿真器里解耦，使迭代周期从小时级压到秒级。
