## 第一部分：诊断——为什么现在卡住

### 1.1 不是「太防御」，是防御的对象错了

你的预登记、独立审计、封印种子、负结果发布线，这套东西是**资产不是负担**。真正的问题在别处：

| | 你现在的配置 | 问题 |
|---|---|---|
| 流程防御 | 预登记判据、独立审计、封印种子 | ✅ 保留，这是资产 |
| **目标防御** | 主目标（正向增益）难达成时，系统滑向能给出确定性答案的副目标 | ❌ 这是病灶 |

**证据**：10-17 一整天 15 个 commit 几乎全是 Q3 认证（浮点外扩界、κ 资格、TOCTOU 审计、G-3 隔离候选），而唯一的正向线索停在 10-13 的 +25.54。Q3 最后停在 κ 资格不成立、NO-GO、止损用尽——结论正确，但它吃掉的是你最稀缺的东西。

**为什么会发生**：证明一个界，比建立一个增益，更能给人掌控感。前者有确定答案，后者可能失败。这不是意志力问题，是任务结构问题。

### 1.2 更深的问题：你在一条很难赢的赛道上比数字

当前主指标是「日效用配对差」。这意味着你要和 SAA + 强规则对照正面打总效用。这很难赢——因为规则对照不弱（explicit_feat 1742.83）。

**而真正致命的是 +25.54 这个数字的结构**：

```
配对差 = [0, +102.92, +24.76, 0, 0]
```

**5 天里有 3 天是 0**。这个结构在告诉你一件事：你的「按 REV/预冷能耗降序预留预算」是一个**静态排序**，它只在预算恰好紧张到某个程度时才起作用。预算不紧张的日子，排序不改变任何决策；预算极度紧张的日子，排序也救不回来。

**静态排序 = 固定的能量影子价格 λ**。这就是间隙的数学本质。

## 第二部分：核心重构——你的问题有一个名字

### 2.1 取货线接拒环节 = Bandits with Knapsacks (BwK)

把你已经做过的事翻译成标准形式：

| BwK 标准要素 | 你的问题 |
|---|---|
| 轮次 t | 订单 i 到达（每天约 200 轮） |
| 臂 a | 订单类别 / 特征簇 |
| 收益 r_t(a) | 接受后的**边际**净收入（收入 − 延迟惩罚 − 品质损失） |
| 资源消耗 c_t(a) | 边际能耗（预冷 + 门开恢复 + 增量行驶） |
| 总预算 B | 710.6548 / 天 |
| 拒绝动作 | 空臂（r=0, c=0） |

**这不是类比，是同构。** BwK 的标准模型就是「随机到达、接受则得收益并消耗随机资源、总资源固定、在线决定接受与否」。

### 2.2 关键公式：λ 是动态的，这就是你缺的东西

LP 松弛与对偶：

```
max  Σ_a x_a · r̄_a     s.t.  Σ_a x_a · c̄_a ≤ B,  Σ_a x_a ≤ 1,  x ≥ 0
```

对偶变量 λ\* = **能量的影子价格**。最优性条件给出接受准则：

```
接受类别 a  ⟺  r̄_a − λ* · c̄_a ≥ 0
```

翻译回你的语言：**「每 kWh 收入 ≥ λ」就是预算预留的数学表达**。

**而你现在的规则用的是固定的 λ。** 「按 REV/预冷能耗降序预留」等价于一个不随剩余预算变化的固定排序。这就是 5 天里 3 天为 0 的原因。

正确的做法是**在线对偶更新**：

```
λ_{t+1} = λ_t + η · (c_t − B/T)        // 次梯度：实际消耗 vs 每轮预算消耗率
```

或更直接地，让 λ 成为剩余预算的函数：

```
λ_t = λ(剩余预算_t / B)                 // 预算充裕 → λ 低（宽松）；预算紧张 → λ 高（挑剔）
```

### 2.3 这是维度升级，不是数字微调

**关键战略判断**：

- 旧游戏：我的日效用 vs 对照的日效用 → 挤第 4 名和第 5 名，很难赢
- 新游戏：**我的遗憾 vs 离线最优** → 对照（贪心/SAA/规则）**根本无法计算这个量**

规则对照没有遗憾界。你用 BwK 可以给出 Õ(√(KT))。

**这不是在同一维度上多 0.3 个点，这是开一个新的评价维度。** 这正是对「刷点难」的正确回答：不要在拥挤的赛道上抢位置，去开一条别人没跑的赛道。

## 第三部分：完整方案（阶段 0–3）

### 阶段 0：解耦 admission controller（1 周）

**做什么**：把接拒决策从 `run_exp_reserve` 里抽出来，成为一个独立、可单元测试的模块。

```
admission_controller(order_features, vehicle_state, remaining_budget, elapsed_time)

```

**为什么先做这个**：
1. 它让你**不跑完整仿真就能迭代接拒策略**——把实验周期从「小时级」压到「秒级」
2. 它是后面所有阶段的唯一接口
3. 它符合你「不修改 MASKCO_code/」的约束

**验收**：在封存的 5 个冻结日上，新模块复现出现有预算感知规则的逐位相同结果（回归等价）。

**产出**：`scripts/admission/controller.py` + 单元测试 + 等价性回归报告。

### 阶段 1：固定类别臂的 BwK 门控（2–3 周）★ 最短路径

#### 1a. 臂的定义

3–5 个臂，按「每 kWh 收入」分档或按「品温要求 × 能耗档」交叉分组。**分组方案必须预登记**，不得按结果挑。

#### 1b. 收益与能耗必须定义为「增量」⚠️ 最大的坑

```
r_t(a) = 接受订单 i 后，重算当日 CVRPTW+品质约束得到的【净收入增量】
c_t(a) = 同上的【能耗增量】
```

**不要用订单的孤立属性**（如「这一单的预冷能耗」）。增量定义才能反映路线耦合。可用快速插入启发式估计，不必每步调精确求解器。

若用孤立属性，BwK 理论会与实际问题失配——这是本方案最容易翻车的地方。

#### 1c. 算法

离线（用封存数据，不碰最终种子）：
- 估计每臂 r̄_a, c̄_a 及置信半径

在线（每轮 O(1)，CPU 实时）：
- UCB-BwK 或 Thompson-BwK
- 接受准则：`m̂_it − λ_t · ê_it ≥ 0`
- λ_t 用次梯度更新或剩余预算函数更新

#### 1d. 主指标（三个，缺一不可）

| 指标 | 为什么 |
|---|---|
| **遗憾**（相对离线最优静态混合策略） | 对照无法计算 → 你的独家维度 |
| **日效用配对差**（40 天，逐日符号 + 符号检验） | 与现有 +25.54 直接可比 |
| **类别接受率轨迹 + λ_t 轨迹** | 机制性证据，证明「预算确实被预留给了高性价比类别」 |

#### 1e. 核心假设（可证伪，必须预登记）

> **H1**：动态影子价格 λ_t（随剩余预算更新）**严格优于**静态排序（固定 λ），且产生非零改进的天数 > 5 天中的 2 天。

这个假设直接从你现有数据的结构推出（3 天为 0），不是凭空猜测。**如果 H1 被证伪——即动态 λ 不比静态排序好——这个方向就死了，立即止损。**

### 阶段 2：保形风险控制校准阈值（3–4 周，可与阶段 1 后半并行）★ 解开你的 Q3 死结

#### 2.1 这一步为什么对你的处境特别关键

你今天（10-17）在 Q3 上撞的墙是：

> 「没有对 `math.exp` 的可核实误差界 ⇒ κ 资格不成立 ⇒ 无法建立可核验的保证 ⇒ NO-GO」

**保形预测（Conformal Prediction）存在的全部意义，就是在没有分布假设的情况下给出有限样本保证。**

你不需要知道 `math.exp` 的误差界。你只需要**可交换的校准数据**。

这是对那堵墙的正面解法——不是绕路，是换一个更现代、且更适配的工具。**Q3 已按预声明止损终止，不该回头；但它的需求（可核验的保证）可以在这里以完全不同、且低成本的方式被满足。**

#### 2.2 具体做法

非一致性分数：
```
s_i = ê_it − e_it        // 预测边际能耗 − 真实边际能耗
s'_i = m_it − m̂_it      // 真实边际净收益 − 预测边际净收益
```

校准：用若干完整冻结日的历史构造分位数 q̂_{1−α}

修正后的接受准则（保形版本 vs 阶段 1 朴素版本，**其余结构完全不变**）：
```
m̂_it − q̂_m − λ_t · (ê_it + q̂_e) ≥ 0
```

保形风险控制（CRC, Angelopoulos et al., ICLR 2024）可控制任意**关于 λ 单调非增的有界损失**的期望：
```
E[ℓ(Ĉ_λ(X_{n+1}), Y_{n+1})] ≤ α
```

可设计的风险：「接受后实际净收益低于承诺值」「能耗超出预测」「剩余预算不足以覆盖后续高价值订单」。

#### 2.3 必须诚实守住的边界 ⚠️

**覆盖保证 ≠ 效用最优。** 保形保证的是预测风险，不是业务效用，更不是「优于 1742.83」。

预登记指标必须同时包含：经验覆盖率、区间宽度、预算违规率、配对效用差、5 日符号分布。

**若只有覆盖率达标而效用无改善** → 如实发布为「校准有效性成立、选择增益未证实」。这进 03_负结果线，是正资产，不是失败。

#### 2.4 校准设计的现实约束

每类订单每天约数十单，条件分位数样本量偏少。需用类别/小时联合分箱、滚动同分布窗口或分层校准，**分组方案必须预先登记**（避免事后按覆盖最好挑窗口）。

### 阶段 3：次模 / 拟阵结构（2–3 周，可选但理论价值最高）

#### 3.1 为什么它契合

在线接拒本质是**顺序集合选择**：每接受一单占用容量、时间窗与能耗，并影响后续机会。

若边际收益递减（次模），单调次模在基数约束下贪心有 **(1 − 1/e)** 近似保证；多独立容量约束可建模为拟阵/多拟阵。

#### 3.2 诚实的风险

冷链收入**通常不严格次模**（路线耦合会破坏递减性）。

**所以这一步的正确做法是「检验」而非「假设」**：用封存数据估计边际收益序列，检验递减性。

- **若成立** → (1−1/e) 近似保证，这是本方案最强的理论产出
- **若不成立** → 负结果 + 解释为什么（路线耦合如何破坏次模性）。**这本身就是有价值的机制发现**，直接进 03_负结果线

**三种结果都能发表，这是这个方案最大的优势——它赌的是结构，不是数字。**

## 第四部分：几何与外部数学方法——诚实清单

你点名了流形、黎曼、双曲。我把每个方向的适配度如实列出。**有些我必须直说不要做。**

### ✅ 推荐做：对称性 / 等价轨迹归一化（适配度 5/5，1–2 人周）

**这是唯一真正适配你问题的几何结构，而且很便宜。**

问题：对称 TSP 中，同一条哈密顿回路有多达 **2n 个序列表示**（n 个起点 × 2 个方向）。掩码重建若在**序列**上监督，会把同一条路线拆成多个「不同答案」，稀释局部信号、让交叉熵在多个正确 token 间平均。

做法（**不要先定义商流形，先做工程版本**）：
- 训练时把参考解的循环/反转等价类同时作为监督目标
- 或解码后对同一条路线做 **canonical form 归一化**，使重建损失只在等价类内计算

⚠️ **带时间窗与冷链时反转不一定产生可行解**，等价类可能小于 2n。必须先检验哪些对称操作保持可行性，再决定等价类。

**这是你论文里「几何/表示」章节最诚实、最便宜的素材。**

### ⚠️ 有条件做：Sinkhorn 可微订单—容量分配（适配度 4/5，2–3 人周，需 GPU）

把订单视为待分配质量、车辆/时隙为容量点，熵正则 OT + Sinkhorn 交替归一化天然满足容量约束。

**只用于订单—车辆分配头，不要对整条路线做 OT。** 后续排序仍交给 MaskCO 或插入启发式。

风险：熵项会把预算「平均掉」（每车接受 0.3 个订单，失去决策意义）。需硬投影 + 退火 + 后处理。

**建议列为 Phase 2。在你的 8 GiB 约束下不要作为主线。**

### ❌ 不要做：双曲嵌入（适配度 2/5）

**诚实结论：在你的问题上，这大概率是修辞包装。**

双曲几何真正擅长的是树状/层级/幂律结构（Poincaré 嵌入的原始动机就是词层级与分类体系）。而 **VRP 路线没有先天树状层级**——节点坐标在欧氏空间，路线是局部邻域 + 容量 + 时间窗共同约束下的组合对象。把路线塞进 Poincaré 球会制造虚假中心，且测地线距离与路线代价之间**没有已知的一般对应**。

检索未发现「把 CVRP 可行路线嵌入双曲空间并取得 NCO 提升」的可验证工作。

**唯一可能成立的场景**：仓库—区域—客户—订单的真实供应链层级，或品类/温控等级构成的异构语义图。此时用 2–4 维 Lorentz/Poincaré 编码层级、再线性投影回欧氏，下游仍由原编码器排序。

**停止条件（必须预登记）**：若在三组曲率 × 2/4 维条件下均不能改善 1% 主指标，且层级恢复指标无差异 → 立即停止，不得继续调曲率。

### ❌ 不要做：信息几何 / 自然梯度（适配度 2/5）

自然梯度解决的是「参数步长与分布步长不一致」，**不是预算预留**。完整 Fisher 估计成本约为参数数平方，在 8 GiB 环境下极易挤占主干激活内存。

预期收益小于实验与复现负担。**这正是你担心的「更精致的防御性研究」的典型形态。**

若真想沾边：局部目标空间的 KL 正则化（「新预测不应过度偏离上一轮可行分布」）——实现只是交叉熵加 KL，1 周可做，但收益需与 KL 系数、学习率等混淆因素分离。

### ❌ 不要做：扩散 / SDE 解生成（6–12 人周，内存风险高）

扩散在 NCO 是活跃范式，但它把完整路线作为生成对象，**不天然包含动态订单的因果到达与严格预算**。多次迭代去噪 + 中间状态缓存在 8 GiB 与在线低时延条件下跑不出可报告结果。若保留 MaskCO 主线，扩散只能是独立的第二路离线比较。

### 🔍 只做诊断，不做策略：TDA / 持续同调（适配度 2/5）

可记录每次 mask-and-reconstruct 后解的变化轨迹、计算邻域持久图，比较基线与新模块的「探索空洞」。**除非证明持久特征能预测约束违反或目标改善，否则不声称带来实质效用。** 风险是维数灾难与循环论证。

## 第五部分：实验设计（必须预登记）

### 5.1 数据切分

| 用途 | 天数 | 说明 |
|---|---|---|
| 离线臂统计 / 残差校准 / 超参选择 | ~25 天 | 不得用于最终比较 |
| 独立调参 / 校准期 | ~10 天 | 滚动校准窗口规则需登记 |
| **封存测试** | **5 天** | 只用于最终配对比较 |

### 5.2 基线（至少四条）

1. 现行封存对照（explicit_feat 1742.83）
2. 固定阈值 kWh 规则
3. **你现有的预算感知规则**（+25.54 那个）
4. **BwK 影子价格规则**（阶段 1）
5. BwK + 保形校准（阶段 2）——**其余结构与 4 完全相同，只换阈值**，这样效用变化才能归因于校准

### 5.3 报告内容

每日总效用、能量预算剩余、预算违规、**订单接受/拒绝数、类别接受率**、预测误差、效用下分位、迟到与品质损失、**λ_t 轨迹**。

5 日配对差报告：逐日符号、均值、中位数、符号检验、置信区间。**不得把 +25.54 在未登记实验中称为已确立增益。**

### 5.4 理论贡献的正确写法

✅ 可以写：
- 固定类别 BwK 在「收益/能耗有界、类别分布平稳、预算充足」下，相对静态最优混合策略遗憾 Õ(√(KT))
- 若分数满足可交换性与单调性（预登记条件），阈值满足有限样本覆盖 / CRC 风险保证
- 影子价格如何纠正类别级预算抢占——**机制解释**

❌ 不可以写：
- 「有限样本覆盖」⇒「保证最优冷链利润」（保形保证的是风险不是效用）
- Õ(√(KT)) ⇒「对单边上界 2544.30 的追赶保证」（那是相对特定基准的渐进界）
- 「使用 Wasserstein/Sinkhorn」本身⇒冷链贡献（必须说明它改变了哪个决策）

## 第七部分：防止再次滑向防御性（流程改造）

### 7.1 给每个防御性任务预登记「停止条件」

Q3 已经做了止损（两轮用尽终止）——这很好。**问题是 Q3 这类认证任务就不该成为主线。**

规则：**任何不直接作用于接拒动作的任务，必须先登记停止条件才能启动。**

### 7.2 分离 AI 的角色（针对你的 ChatGPT + DeepSeek + 本地 Agent 流程）

ChatGPT 的防御性有明确来源：它被训练成「不出错、不给未经证实的结论」。在科研中这表现为永远说「这只是线索不是结论」。

**你现在的流程里只有「防御角色」在跑，缺「进攻角色」。**

显式分离：
- **角色 A（进攻）**：提出**可证伪的强假设**，必须附带明确的失败条件
- **角色 B（防御）**：设计验证协议与判据

具体技巧：要求每个方案必须写出——

> 「如果 X 不成立，这个方向就死了，立即止损。」

H1（动态 λ 优于静态 λ）就是这种假设的范例。

### 7.3 分配「进攻预算」

规定每周至少固定比例的时间花在**能产生配对增益**的实验上，而不是认证与审计。

### 7.4 配送线 8 GiB 门槛别再挂着

要么按现有资源重新登记一个可达门槛，要么解决资源。**挂着不动比降低标准更消耗人。** 注意：本方案阶段 0–2 全部在 CPU 上完成，不依赖配送线。

## 附：本方案的诚实边界

- BwK 假设到达过程、收益、消耗分布平稳；而订单到达、天气、温度、周末可能非平稳。**这是真实的理论失配风险**，需在报告中披露。
- BwK 遗憾常相对静态或离线最优，可能高估相对动态全知策略的表现。
- 保形保证依赖可交换性；在线滚动窗口下可交换性可能被破坏，需检验。
- 次模性在路线耦合下大概率不严格成立，本方案已将其定位为「检验」而非「假设」。
- 本方案所有「预期收益」均为基于文献与项目已定位瓶颈的**推断**，不是已证实的结论。
